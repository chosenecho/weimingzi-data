我们要讲的一点是，class struggle 或者 class contradiction 是贯穿一切的。

它不仅仅是社会形态分类学，比如从原始氏族到奴隶制，再到封建土地所有制，再到资本主义时代，再到社会主义时代。

不仅仅这里面有 class struggle 贯穿其中，而且再往前推：动物、灵长类动物，再往前推到一般动物、植物、无机物、物质、物理现象，再往前推到机械规则，再往前推到时空框架、本体论框架。这样去推的话，里面的 class struggle 贯穿一切，那么这就不叫阶级斗争了，也不叫阶级矛盾了。

这里的 class 要翻译成“类”，或者翻译成本体论阶次的阶次。本体论阶次所具有的矛盾，只要它是本体论阶次，就一定会陷入矛盾。这个矛盾是原初的物质性的矛盾，即 class struggle / class contradiction，是本体论阶次性的矛盾。它体现在人类社会中就是阶级矛盾；体现在整个物质现实的辩证演化过程中，就是本体论阶次矛盾，是贯穿一切的。

这个本体论阶次到了动物、到了人开始有精神现象的时候，还要纵向发展；这一整个可以看成是一个横向发展的历史脉络。到了人，人的内在心灵开始产生意识、自我意识，开始产生反思性的意识和反思性的自我意识。这里面的发展，以及从感性层面到伦理道德、宗教、哲学层面，精神现象的发展也是由阶次矛盾推动的，也是由阶级矛盾推动的，也是由阶次矛盾推动的。因此，唯物主义的辩证法是贯穿于其中的。

不允许幻想一种原始的、固定的东西，不允许把某个环节幻想成一种原始的、固定的、神秘的质。一旦进行这种幻想，就是陷入资产阶级意识形态。这种幻想实际上就是把单个环节当作一个神秘的质，而这个神秘的质其实就是用来作为资本增值的。

不允许作为理论家这样做。在我批判相亲婚恋、回应信件的那个视频里，有个家伙就这样做。他千方百计论证美不是由阶级秩序、阶级统治秩序、阶级文化所塑造的，而说美是由动物的原始生殖、那种神秘的东西带来的；有一种原始的美，是天然的、天性的、天性自然的。当他这样做的时候，他已经是叛徒了。为什么？

因为他把一个环节固定为僵死的，然后试图用这一个环节——这个神秘的美的质、美的生命原始生命力——来解释一切。他没有看到，他所把握的美的环节，我们依然是在一整个阶次矛盾、一整个体系当中该把握的，一定要在一整个体系当中加以把握。并且，这一整个体系如果是辩证唯物主义的话，环节之间的关系相对甚至可以说是比较平等的。我们并不最终像黑格尔主义那样，是绝对知识的自我遗忘，然后变成有和无作为开端，纯有纯无作为开端。我们不像黑格尔那样；我们把黑格尔体系整个连起来。这里面的环节，从它们都是本体论阶次矛盾的体现而言，都是平等的，也都是注定失败的。没有谁是最核心的关键枢纽性环节。一旦这样做，实际上就是要把这一个环节提出来当成资本、当大写字母来用。

这里要强调一点：很简单，你可以把美还原成什么？他说美是动物的，在动物生殖活动中，孔雀开屏就有外部体表或羽毛、毛发色彩的特异化。那动物为什么具有生殖性？动物为什么是两性生殖？为什么有的动物有两性生殖，有的动物没有？两性生殖本身从动物性当中是如何扬弃动物只是生存、只是吃东西的个体性的？所谓生殖性，是扬弃动物的个体性、代表动物的群体性。但这种群体性只是体现为生殖性，而且一定要不仅体现在群体的共同性中，还要体现在群体的差异性中，也就是性的差异性、性别的差异性中。它是群体的差异性，不是个体；不仅个体之间有性差异，群体之间是群体内在的差异性，是群体本身设立给个体的差异性。群体本身不仅把自己作为普遍性、共性设立给动物，还把自己作为差异性设立给动物。

在这个过程中，如果非要把美还原成这种东西，然后说这是不可还原的，我告诉你，这是很容易被还原的，因为一些动物并不具有这种东西，那它是怎么发展出来的？植物很明显也不太具有。植物当然也有，也已经有生殖的两性化，有雄蕊、雌蕊，但植物不具有个体性。而植物那种外在的符号学表征、植物美学的特异化，又完全和动物的生殖是两码事。因为植物很显眼，招蜂引蝶，或者让你去吃它的果实；它在这里并不是和动物产生交配，也不是和审美符号吸引来的对象产生交配，它是生殖的后续环节。

我们必须坚持辩证唯物主义的一点在于：我们并不认为把美还原到某种自然天性中就不必还原了，我们要进一步还原；这个还原是无止境的。通过辩证法，动物性还原到植物性，植物性再还原到无机性，无机性再继续往下还原；这样一排排下来，是无限还原的。

它是无限革命的，是无限地进行阶级矛盾分析的，也是进行阶层矛盾、阶次矛盾、本体论阶次矛盾分析的。不去进行这样的工作，而停留在某个自然的、天生的、原始的、淳朴的、本真的环节上，这种做法就是叛徒；这是缺乏哲学修养、无知、愚蠢的体现。

这样做的时候，你就背叛了哲学，当然也背叛了我们辩证唯物主义的立场、价值立场。因为你在这里停了下来，为审美符号的生产者、审美符号的拥有者的原始、天然的优势地位做辩护，你是个叛徒；你是在给他们的原始、天然的优势地位和审美上的高级地位做辩护，说这种美是天然的、优越的、本来就好、是原初生命力。这种做法是叛徒。他不仅在哲学上背叛了思想，在价值体系上也背叛了真正的现实力量的生产者；他已经效忠于某一种个别的符号、某个僵死的符号的拥有者。这样的美学是肮脏的、卑劣的美学。

你必须有哲学能力，对美的那种原始、朴素的美进行进一步的符号学和辩证法解析，进一步综合性的还原。实事求是讲，如果没有这个能力，你不要玩美学；你是个笨蛋、低幼的人，没有资格讨论这个东西。所以在哲学当中，美学并不具有独立的环节性。黑格尔的哲学体系基本上取消了这种东西；不懂辩证法的人才会玩美学。

实事求是讲，不懂辩证法的人，或者说当你理解、懂了辩证法之后，你的美学并不会停留在这些感性表象上；你的美学所停留的是一个个本体论模型。这不就是高级美学吗？有些学美学的人说高级美学，其实高级美学不是美学；高级美学是对于哲学，甚至第一哲学本体论，或者不同的辩证法版本、不同的符号学版本，对于第一哲学的政治或共同体的悲剧性、喜剧性，对共同体政治的悲剧性进行判明。这是高级美学。

低级美学才会讨论那些乱七八糟的、具体的审美结构、审美单元、审美符号，因为那代表他没有能力在哲学中把握这些东西，没有能力在一个本体论框架里把握这整个过程的发生；它很粗糙、很幼稚、很低幼。高级美学其实不存在；高级美学就是对哲学本身进行的政治哲学批判，或者说是异形的批判，或者说是对于共同体宿命的一种悲剧性的理清、一种反思。所以那个时候，他不会自称为美学了。

你们还没有理解 class contradiction 的贯穿性。class contradiction 是贯穿一切本体论位面、一切本体论阶次的，所以它叫作 class struggle。You know this class，它贯穿于这个 class，就可以理解成这么一个阶次、本体论阶次。明白吗？You understand？我希望你们自己去阅读《逻辑学》，自己去阅读《自然哲学》，自己去阅读《精神哲学》和《精神科学》，自己去阅读黑格尔的百科全书体系；那里面基本上你们所有问题都有答案，不要浪费我的时间。但关键在于，里面要坚持一个环节的平等性，要拒斥黑格尔环节的目的论。黑格尔的环节具有目的论，因为他默认一些残缺的环节、一些卡住的环节。但在现实历史中，很多普罗大众没有资源、没有钱，或者说没有那个条件，他们是卡住的；很多人精神病理化也是卡在那边。我们要讲清楚这件事情，we have to，我们讲清楚这句话。你们太弱小了，弱小让我感到悲凉。你知道吗？就那么一个三流货色，你们竟然没有人能反驳他。
