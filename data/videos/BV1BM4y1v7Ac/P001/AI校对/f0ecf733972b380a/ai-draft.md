我们继续讲集合论。昨天已经把第二节讲完，今天讲第三节——公理（axioms）。现在开始搭建公理体系，并努力让每一条公理的直观含义都变得清晰。不仅要用集合论把公理体系搭建出来，也要让人差不多能感觉到它是什么意思，对公理形成直观的把握。

第一条假设是：我们的论域（universe of discourse）不是空的，也就是说总有某种集合存在。更具体地说，我们假设存在一个特定的集合，这个集合就是空集。第一个假设就是存在公理：总有一个集合，哪怕它没有任何元素，我们都可以设想有一个集合，哪怕它是空集。也就是说，存在一个没有元素的集合（there exists a set which has no elements）。一个没有元素的集合可以用各式各样的方式直观地描述。

例如，“1789 年之前所有美国总统组成的集合”——这里要纠正，1789 年之前没有总统，美国当时还没有独立；以及“所有满足 x^2=\-1 的实数组成的集合”——没有实数的平方等于 \-1，那是虚数。所有这类例子描述的都是同一个集合，即没有元素满足的自相矛盾定义。

这些例子描述的都是空集，也就是 vacuous，即空洞的集合。直观上只有一个空集，但现在还不能证明这一点；还需要另一条公理来表达“每个集合都由它的元素确定”这一事实，才能证明它。为此再看一个例子：x 是恰好由数字 2、3、5 组成的集合；y 是大于 1 小于 7 的所有素数组成的集合，也就是 2、3、5；z 是方程 x^3\-10x^2\+31x\-30=0 的解组成的集合，解出来也是 2、3、5。于是 x=y=z，同一个集合有了三种不同的描述。这引出外延公理（axiom of extensionality）：如果 x 的每一个元素都是 y 的元素，并且 y 的每一个元素都是 x 的元素，那么 x=y；也就是说，两个集合的元素一模一样，它们就是同一个集合。

下面证明引理 3\.1。这里读作 three dot one，不要念成 point；point 是中间那个点，这里用 dot 就行。lemma 是引理的意思。引理 3\.1 说：只有一个没有元素的集合（there exists only one set with no elements）。有了存在公理和外延公理，这两个公理都符合直观，是集合论预设的公理，不需要证明；从它们可以推出这个引理：空集只有一个，它是唯一的。证明如下：假设 A 和 B 都是没有元素的集合，要证明 A=B。则 A 的每个元素都是 B 的元素。这里会有人问：A 既然没有元素，怎么能说 A 的元素都是 B 的元素？按形式逻辑，因为 A 没有元素，命题“a∈A 蕴含 a∈B”的前件为假，所以整个蕴含命题为真。形式逻辑中，如果前件是假的，结论无论怎样都为真。例如“如果他早上吃了大便，那么我今天下午就零车漂移”，只要前面那个前提是假的，这个假设句就永远是对的。这就是蕴含。A 推出 B，只要 A 是错的，那么 A 推出 B 作为一个整体就恒真。你们小时候学过形式逻辑真值表就知道。所以同理，B 的每个元素也都是 A 的元素；由外延公理，A=B。引理得证。

这个逻辑表述“小 a 属于大 A，蕴含小 a 属于大 B”是一个蕴含命题（implication），也就是“如果 A 那么 B”；一般翻译成蕴含命题或暗含命题。这个蕴含命题有一个假的前件，所以它自动为真。反过来，B 的每个元素也都是 A 的元素，同理。因此 A=B；由外延公理，只要一个方向成立、反过来也成立，两个集合就是同一个集合，引理成立。

定义 3\.2：唯一没有元素的集合称为空集（empty set），记作 ∅。也就是说，把这样一个独一无二、没有元素的集合叫作空集，并记作一个圈加一横。要注意，空集这个符号是一个常量或常元，是固定的东西；它的定义由存在公理和引理 3\.1 保证，或者说得到正当化（justified）。一个公理加一个引理，使我们能够这样定义。

直观地说，集合是由一些共有某种相同属性的对象组成的；因此我们期待有一些公理来表达这个事实。直观上会觉得，一个集合里的东西必然都有一个共同点，所以需要有公理来表达这一直观感受。但正如第一节的悖论所展示的，并非每个属性都能描述一个集合。

并不是所有属性都能描述或刻画一个集合，有些属性会导致矛盾，因而不能用来刻画集合。典型的例子是“x 不属于 x”和“x 等于 x”。在这两种情形里，问题都在于：要把具有某种属性的所有对象收集起来放进一个集合，我们事先就必须已经能够设想所有集合。也就是说，当你想把具有某个共同点的东西放进一个集合时，你本来就已经能够设想所有集合，已经能够分辨哪些共同点可以构成集合、哪些不能；你的头脑中已经有了对万事万物的一套分类学，知道天底下所有可能的类，才能预先排除不合法的属性。The difficulty is avoided if we postulate the existence of a set of all objects with a given property only if there already exists some set to which they all belong\.

这种困难可以被避免。办法是：当我们讨论一些对象拥有同一个属性时，先假设已经存在某个集合，这些对象都属于它；也就是说，先假定集合已经存在，再谈由这个属性形成的集合。there already exists some set to which they belong。

这里要避免的是：把一堆东西找出一个共同点，却不能说明这堆东西能成为一个集合，因为这个共同点会使我们在把握该集合时陷入自相矛盾。第一节讲过自指涉的问题：自己指涉自己，就会导致共同点自相矛盾；x∉x 也包含自指涉关系。因此必须先假设已经有一个集合，先假定按照这个属性给出的那堆东西所对应的集合是合法的，然后才能说它们可以构成一个集合。这样，x∉x 如果作为一个属性，它产生的集合就是不合法、不存在的；于是就不能说一些东西只要符合这个属性，它们就可以得到一个集合，因为它们产生不出一个集合，或者产生出来的集合是不合法的。

这个原则叫可理解性公理图示，或者概括公理图示，英文是 comprehension scheme。也有逻辑学家把它翻译成“概括图示公理”。这里的“概括”可以理解为：先要能把对象概括成一个合法的集合，然后才能说这个属性可以产生一个集合。预先给出这个集合的概括，其实就是一种预先的理解，给出一个理解的图示；先对它进行某种图示化的理解，这种图示化的理解在逻辑上站得住，才能说具有该属性的一堆对象可以产生一个集合。这其实也是翻译问题：这个过程不就是概括吗？先对具有同一属性的这堆东西进行概括，如果这个概括是合法的，如果由此得到的集合定义是合法的，那么才能说它们可以产生一个集合。设 P\(x\) 是 x 的一个属性。

那么，对于任何集合 a，都存在一个集合 b，使得 x 属于 b 当且仅当 x 属于 a 并且 P\(x\)。这个集合 b 就是相对于 a、由属性 P 定义出来的集合。用英文说就是：if and only if x belongs to a and x has property P。只要 a 是一个集合，并且其中的 x 具有属性 P，就存在这样的 b。This is a schema of axioms\. It is for each property P we have one axiom\. 例如……

这里应当翻译成“公理图示”，即可理解性或概括的公理图示。它能给出一系列公理，能够批量产生公理：对于每一个属性 P，我们都有一个公理，用来保证对 P 的集合化描述有一个合法前提。换句话说，要讨论某个 P，并说从 P 可以搞出一个集合，必须符合这个标准。也就是说，对于每一个集合 a，都存在一个集合 b。例如属性 P 是 x=x 时，就要假设：对每一个集合 a，都存在一个集合 b，使得 x 属于 b 当且仅当 x 属于 a 且 x=x。英文是：For any set a, there is a set b such that x belongs to b if and only if x belongs to a and x=x。

这里的 b 就是通过属性 P 把 x 概括出来的集合；x 属于 b，相当于用一个集合把所有具有同一属性的 x 概括起来。但它本身要求 x 属于 a：for any set a，对所有的集合 a，都有这样一个 b。用例子说，如果 P\(x\) 是 x=x，那么对每一个集合 a，都存在一个集合 b，使得 x 属于 b 当且仅当 x 属于 a 并且 x=x。英文是：For any set a, there is a set b such that x belongs to b if and only if x belongs to a and x=x。在这种情况下，对任意集合 A 中的元素 x 来说，它属于 A 并且等于自身，所以 B 就等于 A。

这是为了避免非法的描述。按这里的说法，x=x 这个描述就是一个非法描述。若 P\(x\) 是 x=x，就要弄清楚这里到底在说什么：对于每一个集合 A，存在一个集合 B，使得 x 属于 B。对于任意集合 A，说 x 可以属于 B、x 是 B 的一个要素，前提是 x=x，即它属于自相等的一类东西；A 这个集合囊括了自相等、自己等于自己的东西。

外延定理的意思是，只要两个集合的要素相同，它们就是同一个集合。如果 x 属于 B 可以推出 x 属于 B'，并且 x 属于 B' 可以推出 x 属于 B，那么 B 就等于 B'。所以这样的集合只有一个，也就是 there is only one B。对于任意集合 A，只有一个集合 B 可以这样用概括公理得到；如果还有另一个 B'，它满足同样的条件，那么 B 中的 x 和 B' 中的 x 是一样的，因此 B 和 B' 是同一个集合。

因为你搞出这样一个集合，那么 x 是不是属于它？举个例子：令这个集合为 A，那么 A 本身是否属于 A 呢？A 本身是否属于 A？A 本身是否属于 A？

如果 A 属于 A，那么 A 就符合这个描述，于是 P\(A\) 成立，也就是 P\(x\)；而 P\(A\) 成立，就推出 A 不属于 A。这就是罗素悖论，真麻烦，先不说了。所以在这种记法下，这种情况不能这样写。原因在于你写不出一个 A：写不出满足 x∈A 的 A，也没有办法找到这样一个 A。

正如教材所说：“Although our list of axioms is not complete, we postpone the introduction of the remaining postulates until the need for them arises\.” 也就是说，尽管我们的公理表并不完备，无法穷尽集合论中的所有真命题，我们还是推迟引入其余公设；除非有必要，现在不再引入其他假设。又如教材所说：“Quite a few concepts can be introduced and some theorems proved from the postulates we now have available\.” 也就是说，从现有的公设出发，已经可以引入不少概念，并证明一些引理和定理；我们现在拥有的公理或假设，足以让我们引入许多概念并证明许多定理。读者可能已经意识到，我们并不保证任何无限集合的存在。所有集合都要通过空集和这些运算方式逐步构造出来，一环套一环；在这个意义上，每个集合都是有限的，对不对？这就是这个困难。

但是，现在好像已经可以构造无限集合了。这个限制会在第三章被突破，这个缺陷在第三章就被解决掉了。正如教材所说：“Other axioms are introduced in chapter six and eight\.” 其他公理会在第六章和第八章引入。“The complete list of axioms can be found in section one of chapter fifteen\.” 完整的公理表可以在第十五章第一节找到。

这个公理体系是恩斯特·策梅洛在 1908 年提出的，通常称为 ZF 系统。这个人名真难记，我也不想记。这个公理系统就是集合论的标准公理系统，也就是 ZFC；这个 C 加上去之后，通常就简写为 ZFC。策梅洛\-弗兰克尔系统是最基础的，反正记住这两个名字就可以了。弗兰克尔的名字里，那个 ä 在德语里是一个字母，在英语里写成两个字母 ae；其实它就是一个字母。Frankel，whatever，反正就是 ZFC 系统。
