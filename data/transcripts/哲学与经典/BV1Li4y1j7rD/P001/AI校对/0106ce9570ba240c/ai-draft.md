接下来要讲的是第二种真正意义上的主体，也就是哲学意义上的主体，即所谓的 subject。

subject 这个词，我词源学学得不是特别好；可能亚里士多德那里有一个词，指的是一个学科里主题性的、主要的知识，subject 就是主题、主题的意思。它还有“在……下面”的意思：sub 是在下面，subject 就是在某个东西下面的一个东西。其实这个词原本就带有实体的意思，但后来实体用 substance 这个词来代替了。

我们这里要讲的是：对主体性的把握，抽象地去把握它是没有意义的，一定要在它与实体、客体的关系当中来把握。主体一定要在两个关系当中来把握：一个是与客体（object，或叫对象）的关系，一个是与实体（substance，也有人译作基质、基底）的关系。

英语我就不写了。先看第一部分，即主体与客体、与对象的关系。你必须承认，主体是把客体给客体化出来的（objectify），通过 objectification 这个过程才搞出了客体。如果你学康德，必须承认一点：我们以现代哲学的入门——康德（Kantian）作为一个前提，以 Kantian subjectivity（康德主体性）作为前提来讨论问题。如果你不是在这个前提下讨论问题，我觉得我们没有共同话语的基础。你学分析哲学，也要学康德吧？要骂我们学大陆哲学、欧陆哲学的，也得先了解我们在说的是什么，对不对？

我们要说的东西很简单：主体的内在核心，我们把它叫作内在的本质，也就是主体性。主体的主体性，这个玩意儿叫主体性。主体性相当于什么呢？因为我们讨论主体性的时候，前面总要加一个定语叫 transcendental，叫先验主体性；前面都要加一个定语叫先验主体性。

所以严格一点讲，主体这个概念，当我们在西方传统语境里面讨论的时候，特别是从古典哲学、经典哲学一直到结构主义、现象学、诠释学，还包括后来的早期分析哲学，当我们讨论主体性的时候，都是在 transcendental philosophy（先验哲学）的框架里面讨论的。那么，我们要弄清楚什么叫主体性、什么叫主体、主体和客体的关系、什么叫客体化，现在就得了解什么叫先验。

这个问题很简单，只要有一台电脑，你就可以理解什么叫先验。我先清空一下屏幕。什么叫先验？先验简单来说就是 Windows，就等于 Windows；或者你也可以说它等于苹果操作系统。苹果操作系统怎么写我不知道，是 Mac OS 还是什么，我不确定；反正我们就用大家都用过的 Windows 吧。先验就是 Windows，就是操作系统，Windows 操作系统。

先验哲学有两个基本立场。第一，所有对象都是在这个操作系统里面按照它的规则生成出来的；所有东西都是在操作系统内部向你呈现出来的。简单来说，这个世界是模拟出来的，所谓现象性的世界，是操作系统模拟出来的。这是先验哲学的第一点。第二点，主体本身无法被模拟。也就是说，如果这是世界的话，先验哲学认为这个世界就是一个 Windows 操作系统生成出来的视窗；Windows 生成出这么一个视窗，所以它叫 transcendental，这个 horizon 叫先验视域，先验视域。

比如这个世界里面会有一个物，我里面会有一台车——比如说吧，里面会有一辆车，这不是象棋啊，当然我可以把它画得像象棋，或者画得不太像。里面有一台车，那么这台车要在这个窗口里面显现、呈现出来，它必须通过这个操作系统的一些源代码或者什么的，它得有一个基本的操作指令，或者显示指令，把它建构、生成出来。

比如说一个杯子。一个杯子必然要有我们通常会说的关于一个杯子的概念，对不对？那就是先验的概念。或者说我们高级一点，它里面得有各式各样的范畴：有量的规定性，有质的规定性，有模态的规定性——它确实是存在的，它是实实在在在那边；当然它将来有可能不存在，它有一个时间上的各式各样的规定性。这个玩意儿得有各种属性给它拼凑起来。就相当于你这个程序员，你要把这个车写出来，你得写一个 object，写一个对象，然后把这个对象由什么属性给它规定在那边：attribute 一、二、三、四、五，然后 quantity 量多少，quality 这个质是怎么样的；乱七八糟的这些属性都给它加上，就在这个 object 上面。

所以你理解了什么叫先验、什么叫先验性，什么叫先验的视域，你就知道这个世界本身是通过一个操作系统生成出来的。生成出来的这个操作系统有它自己的分类学，有它自己的分析，把一个东西拆分出来，把这个东西整合起来，它有一套自己的机能在那边运作，这叫作先验。那么这个操作系统具体来说，Windows 要说 Windows 10、Windows 7，对不对？Windows 98、Windows 2000、Windows XP，这些版本号，我们会把它定义为某种先验主体性。

主体性有很多种样态，有好多好多种主体性：有黑格尔式的主体性（Hegelian），有 Kantian 的主体性，有笛卡尔式的主体性（Cartesian），有谢林、费希特的主体性。它们是不同的主体性，这相当于 Windows 版本不一样。黑格尔的 Windows 版本是 Win 7，康德的 Windows 版本是 Windows XP，笛卡尔的 Windows 版本是 Windows 95，费希特的 Windows 版本是 Windows 什么 ME，类似的，差不多是这个意思。不同的主体性，就是你这个操作系统具体的范式、操作系统里面的一些设定不太一样。

那本来是一个 GIF 动图，会动的。在黑格尔这个操作系统 Win 7 里面可以，黑格尔式的主体性让它动了，GIF 图动起来了。那么可能在康德那边，Windows XP 里这个 GIF 图可能也动了；但是到了 Cartesian、到了笛卡尔的 Windows 95 里面，这个 GIF 图就动不起来了。如果说这个 GIF 图是某种历史性的、某种历史辩证法的话，它动不起来了，就是主体性版本太低了，不行。

所以这个世界是由一套先验视域给它敞开来的，然后在里面建构出各式各样的对象。这些对象要进入这个视域，要进入这个先验的视域，要成为经验的对象，要可被感知、可被把握、可以被理智读取；简单来说，要被操作系统读取的话，它就要经过一个对象化的过程。在这个对象化的过程里，当然这个对象本身有各式各样的东西就被阉割了。

比如现在量子力学告诉我们，很多东西就是波函数；但在以前牛顿时代，或者在康德那个时代，或者在黑格尔那个时代，把握这些东西还是把它把握成粒子，是一些 rigid 的 body，一些硬的东西、硬的物体，还是把它理解成硬的固体。所以操作系统在读取这些事物的时候，就把原本的那些东西给它篡改了，或者用别的东西给它替代了，让它可以在这个先验视域里面呈现出来。不同的先验视域能呈现出来的东西都不一样，都是不一样的。

有人说，爱斯基摩人一天到晚面对冰天雪地、看白色，他们有几十种、上百种白色；我们普通人可能只有一种白色。这还是在感性层面、感性色彩层面的。再比如说，一些很聪明的人，对他们来说一些概念体系就是起作用的，it works，他能感受到里面的差别。比如一些理工科的高级知识分子，他能感受到不同样式的超弦理论和量子场论之间一些细微的差别；在概念上他能感受到，还能在现实的实验现象里面发掘这种差异。但是普通人根本一窍不通：我哪管啊，我不懂这东西；我顶多知道什么原子核，这种东西就已经很了不起了，而这个在人口里面占的比例并不高。差不多是这个意思。

先验视域决定了，在你这个敞开的系统里面开机之后，哪些东西能够作为一个文件夹被它读取。那么，你们了解了什么叫先验了吗？

先验哲学有两个基本原则：世界是操作系统模拟出来的，这个操作系统就是先验主体性；这个操作系统可能是 Windows XP、Windows 7。如果是马克思主义，那我认为它是 Windows 10，是 Windows 10 操作系统模拟出来的。主体本身没有办法被模拟，主体性本身也没有办法被模拟。因为这个操作系统——它这个模拟者——就叫 subject，这个先验主体、先验主体性就是这个操作系统。先验主体性把世界作为一个对象来表达；这也不叫主动，其实我们没办法拒绝。你说我可以现在停，把这个操作系统关掉，我不要这操作系统，不可能；你不可能让你眼前的世界消失于无，无没办法存在，我们之前讲过。所以主体不得不让自己的先验主体性把整个世界作为一个对象化的把握、语言化的对象化的把握：你可以语言化地把握它，用代码、用表征符号来把握它；也可以叫对象化地把握它，它一个个东西都作为一个文件、文件夹放好了在那边。没办法，你没有办法，这个东西你没法拒绝。你说我要拒绝这种先验主体性，我拒绝它——不好意思，它是先验的，人家牛着呢，是超越性的；你通过有限的指令很难去拒绝它。transcendental 这个词也可以翻译成“超越的”；超越数在数学里面就是不能用有限的代数关系来表示。你是拒绝不了它的。这个操作系统开下来，这个电脑开下来，否则，做梦、睡觉的时候它就会紊乱。我举个例子，你做梦的时候——我举一个非常直观的例子：这个东西什么时候会紊乱？做梦的时候就会紊乱。做梦的时候，比如梦境本身的开始，dream，梦等于这个操作系统紊乱，Windows 宕机，Windows 出 bug，也可以看成它自己修复这个 bug，自己在修复这个 bug。梦境的第一个瞬间，每个梦境的第一个瞬间，实际上就是出 bug 了，因为你沉浸在梦里面。比如一下子我做梦，梦到我是一只小乌龟；你如果是正常人，醒着的时候，你就会去反思：哇，为什么我是小乌龟？就是醒的时候，你有 reflect、reflexivity，也就是有反思能力。大部分人，我靠，突然在现实当中把你变成小乌龟，你肯定就会哇，我为什么变成小乌龟了？但是你如果做梦梦到自己是一只小乌龟，你是不会反思的。这是第一个瞬间。

这个操作系统可能是 Windows XP、Windows 7；如果是马克思主义的话，那我认为它可能是 Windows 10，是由 Windows 10 操作系统模拟出来的。主体本身没有办法被模拟，主体性本身也没有办法被模拟。因为这个操作系统的模拟者就叫 subject，先验主体性就是这个操作系统。先验主体性把世界作为一个对象来表达。

这也不叫主动，其实我们没办法拒绝。你说我可以现在把这操作系统关掉，我不要这操作系统——不可能的，你不可能让你眼前的世界消失于无。无没办法存在，我们之前讲过。所以主体不得不让自己的先验主体性把整个世界作为对象来把握，作语言化的、对象化的把握。你可以语言化地把握它，也就是用代码、用表征符号来把握它；也可以叫对象化的把握，一个个东西都作为文件、文件夹放好在那边的。没办法，你没有办法，这个东西你没法拒绝。你说我要拒绝这种先验主体性，我拒绝它——不好意思，它是先验的，人家牛着呢，是超越性的。你通过有限的指令很难拒绝它。transcendental 这个词也可以翻译成“超越的”；数学里的超越数就是不能用有限的这种数量关系表示。你拒绝不了它。这个操作系统开下来、电脑开下来，你要是不做梦，睡觉的时候它就会紊乱。

我举个例子，做梦的时候，这个东西什么时候会紊乱？我举个非常直观的例子：这个东西什么时候会紊乱？做梦的时候就会紊乱。比如梦境本身的开始——dream，梦等于这个操作系统紊乱、Windows 宕机，Windows 出 bug；也可以看成它自己在修复这个 bug。每个梦境的第一个瞬间，实际上就是出 bug 了。因为你沉浸在梦里面，比如一下子我做梦，梦到我是一只小乌龟。你如果是正常人，醒着的时候就会去反思：哇，为什么我是小乌龟？醒的时候你有 reflective reflexivity，有反思能力。大部分人——我靠，我突然在现实当中被变成小乌龟——你肯定就会哇，我为什么变成小乌龟了？但你如果做梦梦到自己是小乌龟，你是不会反思的。这是第一个瞬间，这就是梦境，是直接的符号性认同，直接的 symbolic identification，直接的符号学认同。

这是梦的第一个反常的地方。梦的第二个反常地方，就是梦境有的时候会让你体验到第三人称视角，或者我们叫上帝视角。我们日常生活中感受的视角都是：我眼睛、我有一个主体，主体在这里，然后看到外面、看到这个世界，这个世界还360度包围着我，这是第一人称视角。我这个主体自己看不到我自己，第一人称是这样；如果在背后看，就是第三人称视角。但在梦里面，你有时候会化身为上帝视角，你会发现你就是空白，那个视域里面有各式各样的人，有这个人、有这个人、有这个人。你会在梦里面产生这种：你是一个纯观察者，一个纯观察者，你不知道是从哪个视点出发的，没有这个视点，而是整个视域向你呈现。

这就是梦境对于这个操作系统本身——梦能够让这个系统出现一种例外状况。包括有的创伤性体验也会有这种梦，也会对这个操作系统、这个 Windows 系统产生一些影响。比如有的神经症、精神病，有的精神分裂症，他的视域就直接裂成两个了。比如一般人的第一人称视域至少身体是完整的，但有的精神病比较严重，身体会裂开、断开，他只能看到上面，他的视域只有上半部分，下半部分看不到。

这就是为什么精神分析天然地和哲学联系得很紧密：因为精神分析就是研究这些反常状况，通过研究这些反常状况，我可以反向破译先验主体性是怎么运作的。否则你怎么判断呢？你只能在这个 Windows 系统出 bug 的时候，看看它源代码是怎么跑的；否则你研究不了，了解吗？所以精神分析之所以和哲学这么紧密，拉康为什么也是哲学家，就是这个原因。我扯远了。

那么我们在这个过程中大致理解了主体和客体之间的关系。用很简单的话说，它是投射出来的，project 出来的；包括主体本身也会投射一个身体出来。这个客体里面包含自己的身体，也包含一个中心化的自我，都包含在这里面，叫 objectify，都包含在这个里面。

我们统一把这些东西都叫对象，所以不要说客体就是主体：客体里面包含自我。这个 self（自我）一般都是客体化的，预先被客体化好了放在这里面的；但主体本身是没有办法被客体化的。subject 本身就是——你想把它客体化成什么？不可能的，这是不可能的，主体本身没有办法把自己客体化。

用一个隐喻说，眼睛看不到自己。我觉得这个隐喻不是很恰当，因为眼睛照镜子看到的当然是镜像，那个镜像也不是眼睛本身。观察者看不到他自身，也就是弄出整个视域的那个视点。外面这个视点没有办法在视域里面成为一个东西，它没办法进去，也进不去。

不过我觉得有更好的方式来做比喻：当你跑操作系统的时候，你看不到源代码，看不到底层代码，不能监控底层代码，它不会实时给你把底层代码生成出来；你看不到底层运算的那些二进制代码，你看不到的。你能看到的话，那这本身就有问题，会陷入无限倒退。你是看不到的。主体是看不到他自己的，这是先验哲学的一个基本预设，也就是 transcendental 的基本预设之一。
