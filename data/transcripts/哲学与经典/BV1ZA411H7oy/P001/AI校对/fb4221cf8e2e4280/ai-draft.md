柏拉图其实就是形而上学历史上的头头。历史上第一个形而上学家应该是巴门尼德，如果把他的残篇算在里面的话；第一个比较强的就是柏拉图同志。《巴门尼德篇》里面其实介绍了六十四种形而上学，但他没有明确把它说出来。我们言归正传，我告诉你这六十四种形而上学是怎么来的。

在《巴门尼德篇》里面，《巴门尼德篇》可以看成柏拉图哲学的一个顶峰，柏拉图形而上学的顶峰。在那之后的《蒂迈欧篇》等其他篇目都闭合了，这个顶峰所开辟出来的璀璨的形而上学大厦就闭合了，就怂了。我们讲后面就怂了；在怂之前的一个顶峰，就是柏拉图的这个顶峰。

我觉得《巴门尼德篇》的哲学史地位应该比它的宗教史地位高。宗教史上有新柏拉图主义，很多新柏拉图主义教士认为《巴门尼德篇》里蕴含了一些密教智慧，一种直观世界本质、宇宙真理的智慧。我今天就要讲这个密教智慧是怎么玩的，但用的是一种现代化的、拉康式的解读，也是从齐泽克开头的一个解读。不过他的解读是不完备的，他没有真正解读，只是起了个头，告诉我们这些形而上学论题很有意思，相互之间可以互相牵制，敞开不同的形而上学框架。你接下来看，我告诉你它为什么是形而上学顶峰，甚至某种程度上可以把它看成人类形而上学的顶峰，因为后面的哲学家没有这么激进地进行过这样的思考。

在那之前，我们先要介绍形而上学里的四组东西、一个矩阵：先是太一 The One，还有大千，我把它翻译成“大千”，就是 The Others，也就是“一”之外的那些乱七八糟的东西、各式各样的他者；还有一个是太素 The Being，最后一个是太虚。

这些词都大写字母开头。所谓“太一”其实就是“一”；“他者”是作为复数的他者，是那些乱七八糟的其他东西，不受“一”主宰，或者与“一”对抗，就是不能被统合成“一”的那些杂多力量。“太素”就是存在，being，但它是所有存在者共同分有的理念，是所有具体存在、具体事物的存在，也就是不同的 beings 共同分有的那个普遍理念，存在本身。最后一个是 nothing，就是无，什么也没有。

这四者构成形而上学的一个基本矩阵，四个角。它们的关系可以这样填：零一一零，也可以填一零一一。这样看上去好像只有二的四次方，等于四的二次方，只有十六种情况，对不对？其实这里还有一个东西是这四个矩阵没有把握的，就是使得它们不仅仅是一个二的四次方等于多少……不好意思，我数学很矬，应该是二的三次方的平方，也就是八的平方，就是六十四，六十四。所以这个矩阵可能有六十四种情况。好了，我们扯远了。

我们具体来看，它并不只是把这四个要素直接放到矩阵里面，就得出了六十四种哲学，不是的；更具体地说，在《巴门尼德篇》里，他直接讲出了八个命题。八个命题两两组合，或者单个重复也算，repetition；单个拎出来、两两组合形成的命题对子，就代表一种形而上学。

为什么我们说这是形而上学呢？因为它没有把主体性放进去，没有把你的主体性那种无条件的否定性、反思性放进去。它是一种比较静态、僵死的方式在进行讨论，他们就是在玩矩阵游戏，没有把主体性放在一个很灵动的位置里，所以它的时间性也比较蠢，稍微有点蠢。那么我们要讲的是，它八个命题是哪八个？

八个命题是：第一个命题，if there is One, the One is not all——如果有一这种东西，那么这个 One 就不是全部，非全。第二个命题，if One is, the One is all——为什么这边不加定冠词？因为只有当他说了这句话之后，它才能被指称，所以前面不加定冠词。第三个命题，if One is the Others, the Others are all——因为这个时候已经出现了 One，所以后面的 the Others 也可以用定冠词来指称，就是除了 One 之外的其他东西。

这几个命题我们先停一下。哎呀，我觉得这东西免费教给你们，是不是不应该？我靠，我应该收钱，而且狠狠地跟你们收好多好多钱。因为……算了吧，反正我这个人也不想做哲学家，没必要。我的自我人格认同、我的职业，my profession is not philosophy，my profession is not philosopher。哎，英语太差了，不好意思。

我们来看这几句话有什么意思。你们都不知道这些话什么意思，对不对？第一个是“如果有一”。这里可以看出第一句和第二句之间的差别，很多人不知道，就是 there is one 和 one is 之间的差别。

这种差别其实理解起来很简单，这里面解读也是有空间的。包括第一句，这个 is 其实是存在动词，就是作为动词的存在，是 be 的第三人称单数 is；there is one 这里的 is 也是。但 one is 这里的 is 就不是了：如果后面跟一个东西，它就是系词，就是“是”。所以我们如何去理解这话呢？第一个 there is one 的意思是，there 就是那里、那儿，就是“那儿是一”，there is one。其实我这样说吧：如何把握“有一”和“一存在”这两种说法的差别？

“有一”和“一存在”之间的这个差别，我们可以用拉康里面的东西来把握。这个时候就是为什么我前面要给你们铺垫讲拉康，要给你们铺垫去讲性关系。你如果这里听不懂，可以回去看《爱欲经济学》，我讲《爱欲经济学》的第二季、第二讲，里面讲了“性关系不存在”，没有性关系这种东西；然后“女性不存在”，女性不存在。“没有性关系”和“女性不存在”，这两个否定是不一样的。你回过头去看什么叫没有性关系、什么叫女性不存在，请你回到《爱欲经济学》第二讲去理解拉康意义上的没有性关系和女性不存在。

这样我们就可以理解什么叫有、什么叫存在。“有一”意味着什么呢？意味着这个“一”是系统的运行模式。在形而上学里面讲“有一”，there is one，其实就是这个 there。这个 there 指的就是这个场域、场域背景、那个架构、那个叙事空间，场域或者说架构；is one 意思就是这个场域是“一”，是“一”。你可以理解成，这里的 there 指的是这个世界的 ontological structure，就是世界的本体论结构：一切东西都要在这个 there 里面存在，对不对？都要在 there 里面存在。

所有东西都要在“there”里面存在，都可以说“there is……”。那么，它与这个东西之间究竟存在什么样的关系？它指的是事物的背景，即事物存在的符号学背景，是事物嵌入其中的那个符号学背景。

因此，这里直接说“there is one”，并不是说有一个“one”存在于“there”里面。不能这样说，因为这是非法的：这个“one”不可能直接存在，它只能作为“the one”。也就是说，在形而上学架构展开、显现出来的那一瞬间，它只能以“the one”的形式出现。这里的差异在于：“there is one”指的是场域本身的模态，即本体论结构的 mode（the mode of the ontological structure）是 one。

这个“one”是太一，是自我同一的一。也就是说，场域本身是一个整全。这样一来，要使逻辑具有一致性，就会导致一个结果：“the one is not all”。当这个“one”——注意它有定冠词，是“the one”——存在的时候，当它“is”的时候，它后面就是一个非全的状态。它显现出来时，既然它是形而上学架构的那个模式，这个“one”就是形而上学 mode 背后的操作系统；你可以把它叫作 Windows One。这个“there”其实就是 Windows One。这个操作系统的特点就是 one，即一、统一，是一个整全的场域。

在这种情况下，这个整全性本身、这个太一本身在显现的时候，如果它要显现，它就不是全体，没有办法囊括全体。或者可以说，场域永远是开放性的，场域是开放的。它不能光有这个“one”，不能光有一，它“is not all”。场域本身是整全的，但光有场域、光有背景是不够的；背景“is not all”，并不是全部。也就是说，它前面还有乱七八糟的东西，还有前景，它还得有前景。这就是第一句话的意思。

所以，我们怎么理解“there is”的结构？这就相当于要理解“没有性关系”。什么叫没有性关系？就是“there is not such kind of thing which is sexual relationship”。性关系这个东西，没有办法作为场域或符号系统自身结构的一种模式，没有办法成为那种整全的模式。也就是说，性关系永远不能成立，因为符号系统自身结构的那个模式，代表着性关系本身一定会失败。所以符号系统必须有一个主人能指；这个主人能指是自我背谬的、自我指涉的，它指涉的就是自己的虚空。你可以回过头去看《爱欲经济学》，以及拉康符号学里面涉及的内容。“没有性关系”指的是：性关系不能成为场域本身的一种主导性的、本质性的存在模式，不能成为结构自身的模式。所以，没有性关系；但性关系 exist，你反过来却可以说“sexual relationship is”。它确实 exist，它作为某些亲密互动（intimate interactions）而存在；它会存在，会以各式各样具体的性关系形态存在。虽然没有性关系，但性关系可以存在，它可以是，它可以“is”。

这是我们关于“there is one”的第一点。“有一”的结果是：符号系统本身的组织模式是太一，是一，是同一的、自我同一的，是整全的、不分裂的。那么它的结果就是：这个太一，或者说这个符号系统，不能成为全部，无法囊括全部。这是巴门尼德给出的一个真理；这确实是一个真理，it's a truth。它是真理，它是符号学，它道出了实情。太一如果主宰了场域，那么这个太一必须敞开，不能自己内循环，否则这个场域就不能敞开。你可以这样想象：如果这个场域是同一的，它一定要有另一个东西塞满它；所以一个敞开的场域一定会面对自身和自身之间的分裂；否则怎么叫敞开？它是一个分裂的。

第二个命题是“if one is”。这里的“is”指的是女性不存在：there is no femininity，femininity doesn't exist。女性性不存在，其实是女性本质不存在。女性本质不存在，原因就在女性本质本身。当然，我们可以说 there is femininity，可以说女性性存在，因为女性性代表的就是符号系统的自我失败。如果你说符号系统的自我失败，那么符号系统的运行模式就是女性性的，it's right；因为女性性标示出来的就是 symbolic system must fail，它必须会失败。一个作为背景性的符号系统，它一定会失败。所以，女性性既然是本体论层面的东西，它就不会存在，永远不会存在，因为它指出的是：符号系统在本体论层面永远是短路的，永远是不一致的，是自我背谬的。

所以，女性性的精确定义是：它能够看到，这个性化的符号系统（sexualized，sexualization），即统摄人的性欲、性认同的那个符号系统，是虚假的；它在理论层面、逻辑层面玩不转，是假的、骗人的。因此，女性性永远不能积极存在，不能现身，不能以一种积极的模式被标示出来。它没有什么各式各样的形态；它永远是一个逃脱把握的东西，eludes your grasp，永远没有办法被直接说出，没有办法存在，没有办法在场域里面现身。女性性没办法自己现身。所谓的女性性，永远是那个永不会现身、却处在男性幻想里的东西：你会幻想有某种超越性的女性本质，这个女性本质是男人所必须的，他必须拥抱这个东西，才能得到性关系上的圆满。所以女性性不存在。你由此就可以理解，所谓“存在”，就是在一个结构好了的符号系统里面现身。

那么，恰恰是因为——你这时要想——符号系统本身是有问题的，是不一致的，那它为什么会让其他东西现身呢？结果其实很简单：恰恰是因为符号系统本身在本体论层面是不一致的，是自我背谬的。所有的本体论、所有的形而上学，我们在逻辑上要讲的这些形而上学，都是自我背谬的，都是一种暴力强行规定的。所以，它必须有东西结晶出来；它的软件层面没有办法不停地跑完所有本体性的力量，没有办法消化所有异质性的力量，所以必须会有东西结晶出来。结晶出来的东西就是 exist；结晶出来的东西是 condensate，就是那些渗出的东西。你可以把符号系统理解成溶液，那些没法被这个符号系统溶解掉的他者，就会渗出来。

那种异质性的他者会结晶、会渗出来，就是 exist。所以在这个意义上，如果“if one is”，如果太一会渗出来，它就没有办法被符号系统消化掉。如果它是“is”，它就不是符号系统的内禀结构；符号系统本身内在是不一致的，它一定会让这个东西渗透出来，让太一渗出来。在这个意义上讲，这个太一，“the one is all”：这个太一就是统摄整个场域的，就会统摄整个场域。如果一个符号系统没法消化这个太一，那么这个太一实际上是一种构成性的例外，是结构性的剩余，是符号系统本身没有办法降服、消化的东西。那么它实际上是什么？它就是符号系统本身，是符号系统自己的本体性存在、本体性根据，就是符号系统自己。你可以这样理解：符号系统如果是一个软件在跑，它背后的硬件就是这个“one”；如果它是“one”，那么这个硬件在符号系统里面就能够统摄一切。

一个很直接的例子就是“Jew”，犹太人。在纳粹主义（Nazism）、第三帝国（the Third Reich）的那个符号系统里面，“Jew”这个东西就是一个 existing one，就是一个显现了的、出现了的、沉淀出来、渗出来的太一。这个太一为什么是 all？因为当时一切社会现象都可以用“Jew”来解释。比如，一个德国的中产阶级会想：为什么我好端端的一份工作就失业了，或者降薪了？这背后是所有的阶级矛盾。或者一个穷人会想：为什么我过得这么惨？他把所有的社会现象最后都总结为“it's Jews' intrigue”——都是犹太人的阴谋。

intrigue，这都是犹太人的阴谋，都是犹太人的阴谋。犹太这种鬼魅一般的构成性例外——这个符号系统，也就是纳粹意识形态、纳粹统治的符号系统，它的构成性例外就是 Jew，就是这个 Jew。

它就是 all，the one is all。在这种情况下，这个 Jew 就是 the one is all：当这个一不得不被析出的时候，它就代表全体，可以统摄、解释一切东西。

这已经是第二项了。那么第三项，每一项都很有辩证法色彩。

第三项是 if one is，the others are all。也就是说，如果太一被析出，其他东西就是 all。这同样是对第二项的一种解答，两者是一样的。

为什么是一样的？就像我刚刚举的例子：the one is all 并不是说直接只有一存在，而是说它会变成其他所有东西的本质性原因，可以从中演绎出所有东西。

所以在这个意义上，这两句话背后又包含一种新的运动：太一被沉淀、被析出，从符号系统的溶液里、从这个 there 当中被析出，然后 is，也就是存在，直接 exist。

但析出之后，这个东西无法直接存在，它没法以自己本来的面目、以其同一的本来面目存在。

对于符号系统来说，既然这个 one 被这个 there 析出，就意味着 the one is an impossible one：它是一种不可能的一，it's an impossible one。

比如这个 Jew——大写意义上的犹太性，或者那种阴谋一般、鬼魅一般的犹太——它不是那种具体的 Jews。具体的 Jews 并不是这个 Jew 的化身。

它只不过是恰好、偶然地 embodied as 这个 Jew。其实，具体的犹太人无论多和蔼、多正直、多善良，也没有办法推翻这个大写的 Jew，无法推翻“犹太人是构成性例外”的那种幻想。

所以，这个东西没法被直接把握。尽管它 exist，but it can't be understood。它不得不被析出，却又是一个不可理解的东西；它代表了符号系统本身内在的不一致性，就结合在那边。

所以这个 one 必定会散成所有的 other 和这个 one；它自己是不存在的，is not itself，它不可能作为它自己存在。one does not exist as itself，或者你也可以说，它不作为它自己存在。

就像这个 Jew，它从来不作为它自己存在，而是作为生活当中的方方面面存在：什么东西短缺了，哪里又爆出一个不好的消息，外交层面又失利了——所有这些都可以说成 it's Jews' intrigue，都是犹太人的阴谋。所以在这个意义上，the others are all。紧接着，从第二个命题就可以导向第三个命题：the others are all。

第四个命题是 if there is one，the others are not all。这很累人，it's burning my consciousness。

这个命题很容易理解：if there is one，也就是说，如果这个符号系统——这个 there 是它的结构，或者说本体论结构——是整全的，那么这些杂多，也就是除了 one 之外的杂多，就很有意思了。我跟你讲，在这里依然很有意思。

如果本体论结构是整全的，这个 one 也不会现身，不会现身，它不会 exist。

但这个时候，它会制造一种效果：尽管我这个 one 不会存在、不会现身，也就是不在场，永远不在场；它永远——某种意义上你可以说它是一个可以 exist 的东西，它有一种可能性：it possibly exists, but never present。

它永远是可能存在，但这种可能性永远不会被兑现。也就是说，这个 one，the one，它是 forever，永远会有可能存在，但永远不会真正现身，never be present。

它永远不会真正在场，不会在那边让你听到它、发现它，永远不会。You can't represent it。因为它永远不会在场，所以你没有办法再现它。这里几个术语之间都是有关系的：represent 就是再现，或者叫表象、表征；你没办法表征它，没有办法对它产生表象。

所以在这个意义上，尽管它不现身，但它总会制造一种效果，让你觉得有这么一个东西，让你觉得 if there is one，好像有这个一存在，但它从来不会现身。也就是说，它实际上从来不存在，它是一个假的存在。在这种情况下，the existence of the One is always deceptive，永远是欺骗性的。

我不知道这是不是这样拼，有可能拼错，是 c i e 还是 c e i。反正它永远是欺骗性的，永远是一种 illusion。

因为你相信这个场域是整全的，所以这是一种信仰，是一种信仰。站在左边的这些 if 这边，都是信仰。如果你信仰它是整全的，也就是站在左边这边的 if，都是你的立场；你的立场就会产生两个结果。

这个信仰就是认为场域是整全的。场域是整全的话，这个一就永远不会真的出现。但它会制造一个效果，让别人误以为有那么一个东西在支撑着它的整全性，有一个太一在支撑着它的整全性。这个支撑整全性的太一，就会使得其他那些杂多——大千世界、具体事物的存在——不再是全部；它们就变成 the others，so the others are infinite。这样，那些东西就是有限的东西。

我们可以把一、四两种情况结合起来看。二、三两种情况我们讲了，它们之间有一个辩证法的关系。把一、四结合起来，就是 if there is one：then the one is not all，这个 one 是非全的；另一方面，the others are not all。把一、四结合起来看，这种立场就是在场形而上学。

其实这就是在场形而上学：在场，但那个在场永远是一个虚假的在场。这个太一，the one，其实永远是不在场的；这就是在场形而上学。

在场形而上学就是认为这个 there 是整全的，这个场域是整全的。相信场域是整全的之后，就会带来一个结果：首先，这个场域本身必然是敞开的，it's not all，它必须分裂。场域必须分裂，必须有 something else——there must be something else，也就是 there must be something。

else——怎么样？filled in it。一定有一些其他东西填充在这个 one 里面，也就是填充在这个场域里面。这个时候，这个 there 就是这个 the one。宇宙其实就是这个，你可以把它理解成 universe；the universe，那个宇宙就是 one，一个宇宙是同一个、完整的一个轮廓，框在那个宇宙里。

如果说它是整全的，那它肯定是空虚的，因为它要敞开。你的第一人称的想象力迫使你这样想、这样想象它。它要敞开的话，里面一定得有东西填充它；而填充的那些东西又必然不是全部，它不能充满，没法把它充满。为什么？

因为它必然会导致一种幻想：你会觉得这个 one，the one，这个太一也存在，exist；这个太一的 existence，太一的存在，就会是一个永恒的幻想。在场形而上学永远认为太一存在，或者说不仅仅是它的存在，甚至是它的在场、当前的在场。它永远是一个幻想，永远是一种暴力。这是一种暴力，但它永远不会被满足，它没法正儿八经地把这个一给出来：你没法在这个场域里面找到一个东西，说这个东西就是那个一。

如果你能找到这个一，那我把这个一击碎，是不是就把这个场域解开了？如果你能找到一个具体的、太一的化身，道成肉身，那我把这个太一的道成肉身击碎，是不是这个场域就裂了？

我告诉你，这个过程就是 Christ 在世间受难的过程。在西方精神里面，Christ 的受难就意味着 the one embodied as Christ and destroyed，然后证明了这个 there、这个超越的太一本身是分裂的；它就会告诉你，太一本身 is not all。
