第一题要证明 the set of all x such that x belongs to A and x doesn't belong to B exists，也就是证明集合 \{x \| x∈A 且 x∉B\} 存在。题目说“所有 x”时，似乎没有给 x 限定范围，但实际上后面的条件已经限定了它：x 属于 A，且 x 不属于 B。只要证明这样的集合存在。

这个集合就是答案。看起来没有限定它，实际上已经限定了它；题目里用的是冒号，我用的是竖线，本质上一样。我把写字板放到上面去。

实际上可以把它写成：x∈A 是范围，x∉B 是附加条件，也就是 P\(x\)。因此这个集合是存在的。根据概括公理，只要 x 属于 A，并且 P\(x\) 能写出来，这样的集合就存在。在概括公理里，这整个集合写成 B 或 B'，于是这样的集合存在。

回过头看，无非是把 P\(x\) 写成 x∉B；它实际上是 P\(x,B\)。所以根据概括公理的图式，这个集合存在。这里的存在和前面说的是同一个，这样证就可以了。

第二个练习要求用一个更弱的公理代替存在公理，即 weak axiom of existence: some set exists。它只说存在某个集合，并不点名是哪一个，所以更弱。题目要求用这个更弱的版本和概括公理框架，去证明原来的存在公理。

证明时，先设 A 是一个已知存在的集合。根据概括公理框架，可以写出一个集合 X = \{x∈A \| x≠x\}。这个 X 就是空集，所以也就证明了空集存在。这里 P\(x\) 取的是 x≠x。题目要证存在一个集合 X，使得 x∈X 当且仅当 x∈A 且 x≠x；用这个办法就把空集构造出来了。

这里 x≠x 就是 P\(x\)，把它代入概括公理框架即可。核心就是构造空集，再得到空集存在：有一个集合是空集，它里面没有元素，并且它存在。

所以做法就是：用一个更弱的存在公理——只存在某个集合，但不知道它是什么样——再加上概括公理框架。在概括公理框架里把 P\(x\) 取成 x≠x，也就是这个集合的一个属性，然后代进去，构造出集合 X；这个 X 就等于空集，证明完成。这也没有太多技术含量，就是教你如何构造空集。

第三个练习是 prove that a set of all sets does not exist，也就是证明万集之集不存在、一切集合的集合不存在。证明用反证法：先 suppose that there exists a universe set，假设存在一个全集。这个符号看起来像 U，是希腊字母里的哪一个我不太确定，先不管它怎么念。

先假设这个全集、万集之集存在。然后根据概括公理，可以设存在一个集合 B，它的范围就是这个全集；再用概括公理描述这个集合的范围，并把后面的 P\(x\) 写成 x∉x。这里的 x∉x 就是筛选条件。

如果存在万集之集，就从中筛选出那些“不是自身元素”的集合，也就是自己不是自己要素的集合，把它们从全集中筛出来。按照概括公理，这样能筛出一个集合 B。也就是说，假设万集之集可以用集合的方式描述或把握。但接下来要证明这不行：不能这样去把握万集之集，因为它包括自己。

那么按什么标准筛呢？就是按“自己不是自己的要素”这个标准，从万集之集中筛出这样的集合。很多集合自己都不是自己的要素，比如空集：空集自己不是自己的要素，因为它没有要素；如果它要是自己的要素，就得形如某个包含自身的东西，但空集没有要素，所以它当然符合这个定义。若有万集之集，空集也应该在里面，就可以这样把它筛出来。Now we show that\.\.\.

现在要看这个筛出来的集合 B。只要证明 B 不属于这个全集，它就不是万集之集，这就与假设矛盾。

通过概括公理的定义来看：按这种方式写，B 肯定是一个集合，因为它就是根据概括公理得到的。反过来说，假如 B 不能用概括公理来刻画，那就会矛盾；也就是说，如果 B 不属于这个全集，那么 B 就不是一个集合。

事实上，如果 B 属于这个万集之集，那么要么 B∈B，要么 B∉B，只有这两种情况。按概括公理的定义，x∈B 当且仅当 x∈全集 且 x∉x；这也就是概括公理的形式：x∈B 当且仅当 x∈A 且 P\(x\)。

把这个代入：A 就是万集之集，P\(x\) 就是 x≠x，所以 x∈B 当且仅当 x∈全集 且 x∉x；在全集存在的情况下，也就是 x∈B 当且仅当 x∉x。

写成这样之后，现在考虑：如果 B 属于全集，那么要么 B∈B，要么 B∉B。若 B∈B，把 B 代入定义，就得到 B∈全集 且 B∉B，于是 B∉B；若 B∉B，那么它满足 B∈全集 且 B∉B，根据定义又推出 B∈B。也就是说，B∉B 会推出 B∈B。

这里面的 X 可以用任意集合来代替，都是 any x，任意集合都可以代进去。集合论里的要素本身也可以是集合，所以当 B 属于这个万集之集时，它就满足这个要件；并且如果 B∉B，它又满足另一个要件。两个要件都满足，就可以把“当且仅当”往左边推，推出 B 属于 B。这样又推出矛盾，对吧？

先看第一小题 a 的证明。假设这个集合是万有集。若 b 不属于 b，就会推出 b 属于 b；而 b 属于 b 又推出 b 不属于 b。这两种情况都矛盾，说明一开始的假设是错的，所以 b 不属于这个集合。于是证明了 b 不能属于它。既然存在一个集合不属于它，它就不是万有集。换句话说，假设它是万有集，却能推出它不是万有集。举个类比：假设某物是男人，最后却从这个假设推出它不是男人，那就意味着“男人”这个假设不可能成立。同样，假设这个集合是万有集，却推出它不是万有集，就说明万有集不存在。这种假设不能成立。第一小题 a 就证完了。

第一题 a 用的是反证法。b 要证明的是：对任意集合 A，总存在某个 x 不属于 A。这个结论其实很直观：对任何集合来说，都不存在万有集；一个集合不可能囊括一切。所以 b 不必再单独证明，因为 a 已经证明不存在万有集。更具体地说，每个集合都有不能包含在自身之内的要素，也就是不存在万有集。要证明 b，可以把命题 for any set A there is some x not belonging to A 写成它的逆否形式：不存在一个集合 A 是万有集。这样 b 就证出来了。反过来，如果一个集合 A 把所有要素都囊括进去，那么 A 就是万有集。

第四题：Let A and B be sets\. Show that there exists a unique set C such that x belongs to C if and only if either x belongs to A and x does not belong to B, or x belongs to B and x does not belong to A。也就是说，A、B 都是集合，要证明存在一个唯一的集合 C，满足：x 属于 C 当且仅当，要么 x 属于 A 且 x 不属于 B，要么 x 属于 B 且 x 不属于 A。这里的“或者”是互斥或，两者只能有一个成立，不能同时成立。也就是说，x 要么是 B 中而不在 A 中的元素，要么是 A 中而不在 B 中的元素。这个集合相当于 A 与 B 的对称差，即 A 并 B 再减去 A 交 B；C 就等于这个集合。

证明时要把 C 的两部分写出来。令 C1=\{x：x 属于 A 且 x 不属于 B\}，C2=\{x：x 属于 B 且 x 不属于 A\}。用概括公理，可以把这两部分分别写成上述形式。再令 C=C1∪C2。根据并集公理，C 存在；而只要它能写成并集，根据外延定理，它的外延就确定了，因此它是唯一的，不必再证。若一定要证唯一性，就假设有另外一个东西也是 C，然后证明它们的要素完全相同。

第五题：给定集合 A、B、C，证明存在一个集合 P，使得 x 属于 P 当且仅当 x=A，或 x=B，或 x=C。也就是说，P 相当于 \{A,B,C\}。题目原文是 There is a set P such that x belongs to P if and only if x=A or x=B or x=C，其中 A、B、C 是给定的集合。这里要证明这个 P 存在。

要证明 P 存在。P 相当于 \{A,B,C\}，也就是要证明可以写出三元的无序并列集合。题目提示使用配对公理和并集公理；关键是把 A、B、C 并列起来，说明这样的集合存在。

这部分不要证，它属于公理，也就是配对公理（axiom of pairs）。按照配对公理，可以把集合罗列出来。由配对公理，存在集合 \{A,B\}；同样，也可以写出 x 属于 P 当且仅当 x=A 或 x=C，从而 \{A,C\} 也存在。并且可以把 \{A,B\} 与 C 作为两个对象并列起来。反正按照配对公理，\{A,B\} 和 C 这两个集合一定可以存在，因为这就是配对公理的定义。

然后用并集公理。并集公理可以直接照抄：取 \{A,B\} 与 C 的并，得到 P=\{A,B\}∪\{C\}，它存在。这个 \{A,B\}∪\{C\} 其实就等于 \{A,B,C\}。因此，用并集公理就证明了 P 存在。再用并集公理，就可以把 P 的定义写出来：x 属于 P 当且仅当 x=A 或 x=B 或 x=C。这个定义写出来就结束了。若在这里再抄一遍并集公理，会发现它的定义在逻辑上和这句话等效；那就不抄了，不浪费时间。

第二个要求是推广到四个元素。做法一样：可以先取三个元素，再加入第四个元素 d，然后用并集公理；也可以用二加二的方式，结果相同。

第六题要求证明某个关系对任何 x 都不成立。大意是：对任何 x，“它是它的子集”这个说法都不成立。这里涉及的是真子集关系，也就是一个集合是另一个集合的子集，但不等于那个集合。这个关系在教材里出现过。

教材里面出现过，不过他用的字母不太一样，其实就是这里的这个字母。这个字母表示所有子集构成的集合，也就是 power set。一个集合的幂集，就是把它里面各式各样的子集组合到一起。题目要你证明：对于任何一个集合来说，它的幂集不是这个集合的子集。任何一个集合的幂集都不可能是它自己的子集，因为阶次不一样。这个东西其实很好证，阶次不一样。

因为幂集一定比原来的集合高一个阶次，这可以理解吧？它相当于比原集合多一个括号。它的子集肯定包括它自己，而它自身在幂集里面又是一个要素，所以相当于给自己外面多套了一圈括号，那它就不可能再是原集合的子集了，对吧？

然后它的证明也用来证明万有集不存在，因为它同样体现出阶次差异。对万有集来说，它的阶次永远要比自己多一，那不可能；一个集合的阶次是确定的。你如果设想有一个万有集存在，它里面包含自己，那么一旦它包含自己，它的阶次就要多一，所以它没法包含自己，它的阶次就自相矛盾了。这个其实很好理解。

所以这种东西是无法证明的：你要它成立，那必须这个也成立，那你这个没法成立。为什么无法成立？因为你说空集的要素集合，假设空集可以有一些要素集合，形如 A1、A2、A3，这样的要素集合是空集的要素集合。但是它本身不存在，你就没法说某些 x、某些要素不属于这些要素集合 A1、A2、A3；你没有办法说 x 不属于 A1、不属于 A2、不属于 A3。所以在这个意义上，你没法说一些要素不属于它，说明这集合是非法集合。或者说任何集合都可以冒充说我属于它，我也属于它，那它就变成万集之集，对吧？

这就是一个补充。这道题最后它的证明实际上是集合论里的：一个合法集合，不仅仅说里面有东西——你可以先设定这个集合里面有东西，先设立存在这么个集合，而且这个集合里面有东西；但既然你现在承认它是个集合了，那它里面也必须有一些不在其中的东西。那你说 x 不属于 A，你怎么证明？你得给出某种标准吧？A 得给出某种标准，对不对？

你可以用概括定理，比如 A 等于一个什么，x 属于 A′，然后 x 得这样，you understand？然后 p\(x\)，它得这样，它得给出这么一个标准出来。现在由于 A 是空集的要素，它给不出这个标准，给不出这么一个标准。A 本身是空集，它没有办法通过概括定理给出这样的标准出来。所以它的证明里面才会出现这个狗屁玩意儿。其实我在播的时候、在那个视频里面也说了，这里面会出现这个东西，这个东西让人感觉比较头疼。

我看了半天，想它干嘛，是在搞逆否命题还是干嘛呢？其实里面贯穿的是一个集合论思想：不能有万集之集，不能有一个什么东西都在里面；或者说不能有一个集合，它没有不是它的要素的东西。它必须有一些东西不是它的要素，必须有一些东西不属于它，它才能是个集合，好吧？
