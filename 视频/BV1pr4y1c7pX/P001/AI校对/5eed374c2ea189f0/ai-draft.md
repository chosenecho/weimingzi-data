我们要进一步讲一下，需要补充一下。我要补充的是康德的《实践理性批判》。因为我们前面讲的那些比喻，其实都是《纯粹理性批判》，甚至引向一个科学共同体、科学研究共同体。那么康德在道德层面的《实践理性批判》、他的伦理学，我们用游戏做比喻，差不多是什么意思呢？

他的意思就是告诉你：这个游戏本身，这个世界、这个游戏本身，这个端游本身没有主线任务，本身是没有主线任务的。那么它唯一的任务是什么？这个游戏唯一的任务就是所谓的实践。我们前面已经说过，所谓的实践是什么？

实践就是不停地做出新的 mod，然后发布、publish 这些 mod，再让所有人过来 debug 这些 mod。这个游戏在康德那里看来，这个世界、这个游戏本身就是一个 mod 模拟器；我感觉它就是一个 mod debugger——通过 mod 来对游戏本身进行 debug。

所以在这个意义上，康德式的主体、康德式的伦理主体是一个程序，是给主创程序员打下手的 debug 程序员。他没有权利知道源代码，也无权知道源码；他不能知道代码本身、源码本身。康德的伦理实体就是专门、不停地、永远地为上帝打下手。

上帝是写源代码的程序员，而这个主体的作用就是通过实践不停地做一个又一个的 mod。每一次实践都相当于做一个微型、迷你的 mod。每一次道德实践——在康德那里，道德实践和理论实践是统一的——因为他的实践理性实际上就是纯粹理性运动起来的一种动力学，理论理性和道德这两种实践、两种活动，不停地生成这些小的 mod。

然后通过普遍必然、普遍化的方式去探测它有没有所谓的必然性。也就是说，我把它推而广之：这个 mod 是不是可以在所有电脑上都跑起来，在所有情况下都能跑起来，在所有终端、所有环境下都能跑？如果是，就可以，没问题，这个 mod 没问题。

这样搞下去，越搞越多，康德主义的世界会变成一种什么世界呢？它会变成一个 mod 群组，一个比原版游戏更好玩的世界。康德认为，在这个意义上，人和上帝是一种相对比较平等的关系：你做一个 debug，和一个 creator，就是相对比较平等的关系了。如果最后你把这个世界上的所有本地文件、所有情节、所有环节、所有内容都 mod 化了，上帝最终就会觉得你实在太厉害了，他就会邀请你。

他会邀请你，从民间制作者变成这个项目的程序员，成为程序员的一员。

这就是康德抱有的无限实践的理想。所以在这个意义上，灵魂是不死的。你给他 debug，他怎么会让你死呢？灵魂不朽，上帝是不会让你死的。你这个免费的、不是 996 的，而是 007 的 debug 程序员，你们老总怎么好意思踩你呢？

不会踩你的。所以上帝会邀请你。最终你把所有东西都 mod 化了，你作为民间大神，上帝会赠予你一个无限长的点卡。

而且康德要说：你我都做这样的事情，而且这个事情本身就是你做这款游戏的根本目的，所以这个事情本身就必须普遍必然化，我这个 debug 活动要普遍必然化。也就是说，我不会停止；如果我会停止，就意味着我做的这些东西有可能会消失，有可能会变得没有意义，对不对？

所以在这个意义上讲，他对整个世界的目的论认定，就是这个世界通过主体的 debug 进行自我修复。世界在进行自我修复，而它既然是修复的，就必须被 preserved，被保存在那里。所以在这个意义上，我们也可以推出灵魂是不朽的。

这个修复的过程是无限的，是趋向无限的：那种特殊的、病态的东西会不停被这个实践的主体修复掉。灵魂是不朽的。在康德看来，人死了、身体被烧掉了，可能只是换个工位而已；甚至会认为：太厉害了，我们调个岗，下一次让你投胎做量子物理学家，这次让你做哲学家是亏待你的，下一次让你做量子场论大佬，让你投胎做薛定谔，或者投胎去做未来某年的新哲学家。

他认为世界的目的就是自我修复，不断进化、自我修复，或者越来越趋于完善、完满。所以它有三个假设，其中涉及完善、完满；另外还有上帝存在和灵魂不朽。这是一个三位一体的结构，所以又俨然是一副神学的样子。这样我们差不多也知道，康德的实践哲学作为一个游戏，是什么意思。

也就是说，这个游戏本身已经不是游戏了，它本身变成一个训练程序员的程序；或者这个游戏自己的目的，就是让别人玩它、玩出 bug 来。所以这个游戏始终是一个内测版本。从康德的实践理性角度看，这个游戏是内测版本，玩家在里面玩是不删号的，是永远不删号的，因为它永远是个内测版本。

你也没办法删号，进去了就别想出来。最后，康德认为，当我们实现了这个使命，我们的意识、我们的主体就会和上帝合二为一，融合在一块，变成一个完满的存在。这就是民间大神重新回到他的游戏开发组里面去了，差不多这么个意思。

以上是补充。在讲费希特之前，我们先补充这些。
