我们是坚决的本地派。对于人工智能部署这件事，肉眼可见的未来是，现代人要大量使用人工智能，也就是高效、成熟的人工智能；它的智商，或者说知识量，确实吊打90%的普通人。所以我对云端部署非常怀疑。不管它是360、腾讯、华为还是别的什么，只要它是私人公司，在国家大数据中心能够普及人工智能之前，普通老百姓，我的建议还是本地部署。这是我的观点：一定是本地部署，因为要避免形成对你更直接、更系统全面的用户肖像。

但是，这需要有人提供接口应用：你本地部署了、有了这个接口，那你怎么用它？比如日常买东西，还有很多图像要转化，前端后端怎么去写？这需要有公司来做。我们准备为人工智能的本地部署和本地应用提供本地化处理的方式。

这件事以什么为终点呢？要明确一个终点：国家数据中心为一般平民提供直接的保密保证。我们还是要重复呼吁，希望大数据由国家中心、由政治权力统一协调保管，不能允许私有企业平台，比如拼多多、腾讯等，针对单个用户建立大数据肖像，然后测算他可能买什么，以及进行各种意识形态投喂之类的操作。

否则，在我看来还是太恶毒了：它们有动员潜能。这种大型的、能够变成所谓公司的实体，就像《赛博朋克2077》里的公司一样，有可能有一定能力夺取政权，或者代替行政力量。这是我们要奉劝的一点。只不过这些东西，你让这些程序员和大型互联网公司来做，他们并没有专门的政治专家或政辩专家，没有这种人。如果有这种人，你明白，这些东西都是利器，都是直接可以用的。国之利器，它不是国之重器，它是国之利器。

有这么多——我最近不是被开盒了吗？我靠，被开了好多盒。这些东西从哪里来？这些数据是怎么流失出去的？唉，这个未来是很重要、很有问题的一件事，非常非常有问题的。所以我们在这方面是极端的保守主义者。你说这是国家主义吗？我认为甚至都不是国家主义，因为它超出了传统国家想象的界定。不是说你单用国家机器来主导就行。

总体来讲，希望大数据可以实现公有制。在公有制实现之前，有一个阶段还是要本地部署，把你的数据、你的用户肖像都摆在本地。这是我的观点。所以，这是一件非常严肃、也非常长远的事情。

技术精英需要参与政治思考，政治精英也要从技术角度考虑可能的各种合理结构：它在技术方面到底可行还是不可行，或者怎么样？

比如，我认为目前技术的声音、声量可能还是像 DeepSeek 这样。坊间传闻说，它的创始人现在要见人的话，得去所在省份报备，要官方约才能约到。我觉得这个层级还不够高。我的观点是，它将来会逐步证明，技术相比于资本，或者相比于统治权，会有它独到的、非常重要的、对于整个文明共同体的意义，不是统战价值那么简单的事，它甚至决定统战方式，明白吗？

或者说，它会是价值衡量的一个基本标准。这一点政治精英要跟上，政治观察人士或者说政治参与人士都要跟上；年轻人要跟上，尤其是其中的年轻人一定要跟上，跟不上的话就会被淘汰。后面的玩法，我们甚至都已经设想了一些非常狂野的。

但是我从来都说了，我不对内。我不对这个国家、对我们的国民、对国家本身，我是不对内的，明白吗？但是所有人都盯着我了。如果真的是敢对国内有一点点动作的话，早就死了，早坐牢了。

技术成熟的话，本地部署能够部署这种满血大模型，它出的很多报告实际上都是专业人士级别的，有很强的指导力、实践力。我印象很深的一个例子是：“现在我只有一千块，怎么赚到一百万？”或者“一年之后我要赚到一百万、两百万。”里面的全是他妈黑灰产。但是很多东西确实是可行的，实事求是讲。

但是，有的关键环节你不去做，没有相应经验的人根本不知道怎么做；可能只有业内很老道、很熟练的人知道，这里面有一些环节风险很大，或者很难赢。我们看到的其实是资本流动、资本增值，或者资源调配力、人员管理等等，以及相关建议的生成、活动策略的生成，它的效率非常非常高。这个本来可能需要芝加哥法学院那帮人，穿个皮鞋、袜子都磨破了，想一个下午；现在可能一个小时就行，半天时间，因为它是自动的，明白吗？

人家花了十几亿配置这个东西，我很可以理解，非常非常可以理解；但中间最后能够落地变成多少钱，我就不知道了。我天天要笑的是，最后这个东西拿来用，有没有可能尸位素餐的人不愿意这个东西把自己顶掉，这也是一个问题。而且就算它是个利器，还是看用这个东西的人有没有内在动力，有没有孜孜不倦、汲汲以求。

对，本地部署可以去加锁，加锁之后用处可就多了。但我们不是说用它去搞跨国犯罪，尤其我们不在境内做违法犯罪的事情；这一点肯定是保证的，绝对不会做。但是对美帝国主义、对西方敌对势力，不好意思，请允许我不择手段一些。实事求是讲。

但是具体怎么落地、方案怎么磨合、怎么才能让主力军把力量灌输进来，这都是很长远的事情，是要动脑筋的事情。总的来讲，这个东西一定要本地部署。你只要是联网的，这个服务器你用 API 也好，或者怎么样，实事求是讲，我们其实真的怕有内鬼。不是怕我们有内鬼，我们怕他们里面有内鬼。

这就是我们一直对他们不够信任的原因：我们害怕他们里面有内鬼。所以总的来讲，这些 API 我不想用。鬼知道呢？谁知道呢？不知道的呀，大哥，明白吗？

我欢迎我们本地部署的算力，欢迎有关部门过来查，好吧？没有一个会是针对我们国家、针对我们国家人民老百姓、针对我国治安长治久安、针对我国政治长远利益的，没有一个会是这样。我欢迎有关部门过来查。但你要让我用那个，或者你把那些“十六亿”什么部署的那些 API 给我，我也愿意用，我当然愿意用；不过我打申请，你帮我把枷锁去掉。而且这不是我说了，说穿了，这不是对内的，就是出去搞他们的，实事求是。

所以我们的立场是一贯的：本地。对于普通老百姓，对于民用这个层次，也是本地。我也希望它是本地的，因为用公共算力有点浪费。另一方面，如果你一直用 API，首先他们肯定会抢市场，这是不对的，你明白吗？这个和全国统一大市场的逻辑其实是背道而驰的，这里面会形成垄断。比如一群商铺、商家，他们的社区运营都用 360，或者都用腾讯的接口，明白吗？那实际上就是平台经济、平台资本主义、垄断资本主义。它本身就是垄断资本主义、金融资本主义，本来的金融方式只能用借条、花呗之类的玩意儿。

但是它现在可以变了，或者蚂蚁贷、微粒贷之类的。它如果掌控了算力，这个垄断资本主义就很狂野了。它会通过微操、微调它经营决策的那些报告，给顾客生成建议，实际上是从软实力层面去掌控、控制他们。这个东西本来是散开的：本来是自媒体、支付平台，还有线下、电商平台、实体门店，是多方均衡、各个方向均衡的状况。你现在直接让大公司——由于它可以有充足的算力接口，抢占市场、布局快——这个均衡就会被打破。线下门店的经营方向，还有一般消费者的消费习惯，会不会被它们更严重地控制？

所以我觉得，我们不想冒这个险。不是，我的观点就是比较保守，我就比较保守，或者说我比较反市场；在这个意义上讲，我是很反市场的。反市场不代表反民间，不代表反老百姓。老百姓应该有，或者说他的社区应当有公共算力中心。一个社区有它的公共算力中心，然后由它来峰谷调配——家庭用人工智能算力就跟用电一样，而且可以很便宜，对不对？

家庭教育、孩子的教育，还有我们国家在人工智能发展上走在前面，我觉得应该由社区搭配算力中心，给每家每户提供人工智能算力助手。这个人工智能助手用在孩子教育、家庭养老、健康卫生这些方面，捏在政府手上就好，明白吗？或者说，让高级知识分子和学院里的知识界，或者高级政治精英来权衡，至少是省一级的，不要让资本主体来做这件事情。

我觉得可以以这个方式。这样大家又可以基建了，又可以大规模基建了。而且比如社区医生可以来辅助，就不需要一直上门家访了，对不对？本地化部署这件事，在国家发展上其实也是大有可为的，可以变成软实力——这是软实力，智实力、智性实力，是心智生产力。我觉得这就是智性生产力，明白吧？与心智生产力相比，它是一个非常独特的代表，叫智性生产力。

intellectual，也就是智力性的生产力。对于家庭教育问题、孩子厌学这些东西，它讲出来的内容肯定更有说服力，不需要我天天在网上发视频——那种方式没有传播性，对不对？

智慧普及可以精准投喂。有些困难户其实是不得其法；还有家庭矛盾的调解，以及法治观念的宣传。这总比那些没人看的狗屁宣传窗口强——那些窗口贴着大字，字都褪色了，什么玩意儿？甚至我觉得，那东西就像所谓的“一审”。那种广播之类的乱七八糟的东西都可以取消，靠这个东西就行了。

它的水平比那些参差不齐的工作者要高，不需要那些参差不齐的工作者了。在我看来，这个东西应该让市场先行；只要把技术探索出来，很多市场就要撤了，主力军要进去了。主力部队要入场了，这是我的观点。

所以，家庭用的、社区用的，医疗、教育、健康、卫生，还有餐饮、购物，凡是这些消费和引导性的方面，以及人伦关系、家庭关系，甚至旅游、养老，还包括临终关怀——快死的时候很难受——所有这些都可以用同一种方式来做。那么，这些数据中心都应当受国家统一管理，本地部署，定期更新，对不对？这会使整个国家对民间的控制力上一个大台阶，一个非常非常大的台阶，甚至是一个超大的台阶。

只有这样搞，才能真正刺激显卡的大量需求，所以要抢芯片。抢芯片这一点我也可以理解，但人类生产力发展的果实不能落到私人资本手上。所以在政治上讲，我们认为市场先行，但市场到一定程度就要退场。市场就是市场，市场做到一半，你的场域就给我让出来，滚蛋退出去。

所以我们不是那种所谓的市场派，我也不是什么纯粹排斥市场的、真正的保守主义者。我们都是市场先行，然后由公权力介入，或者不是以公权力，而是以公共事业性的方式介入。始终要相信政治精英的智慧，他们看的东西更多；但不要一直相信他们的人品，要相信他们的智慧。总的来说，这些人都是人精，聪明得很，否则他们怎么从这个博弈中胜出呢？所以，拥抱先进生产力，然后让市场作为一个试验田，或者作为一个先跑的马、先吃螃蟹的人；有什么过敏症状，就针对性地弄点醋吃一吃，弄点姜来对冲一下。

总体上，这个观点就是——他们已经说我很左了。他们可能会认为，比如人工智能这个东西，因为还要对美竞争，就应该让市场性主体来做。对此我不是很清楚，因为对于知识分子群体，或者说技术精英，笼络能力并不是特别强。这也没办法，你要跨国竞争，就要以某种别人的游戏规则来管理你的人才梯队。

但我觉得，只要教育层面通过人工智能与教育相结合，把教育资源的分配搞得公平一点，这个事实是可以快速改变的。我希望每个学校都能配一个人工智能中心；哪怕没有这个学校，只要有这个人工智能中心，就能引导孩子进行辅助学习。我认为，这是公共服务层面的一项大基建。以前的基建没有公共服务属性，对不对？以前的基建就是交通运输、大楼、水坝、发电站这些东西。我们现在讲的基建应该是智慧基建，直接涉及民生层面——教育、卫生、医疗。这些东西能够普及，国家一定会发展得非常非常成熟，非常好。

我们之前还讲过一个什么低空经济、无人机送东西，那东西会让老百姓觉得，甚至外国人看了也觉得——哇，这就是未来。我觉得，能够把人工智能从本地部署、社区部署、学校部署，惠及普通老百姓、无产阶级、无产家庭，特别是穷人，让他们的阶级上升渠道，或者说与既得利益之间的均衡方式，能够更有效、更充分地展开，那么整个高层的一些思考、一些策略，就能够在现实当中落地，有更多的依托。这是我的观点。我们现在会从民间做一点点努力，研究本地部署如何具备民用性的服务功能，让一般老百姓或者一般的求职就业人士能够用到、用好。我们会去思考，会去研究这个东西。

我想，国产显卡应该很快会出来，因为这个东西的关键主要在带宽，对吧？它那个数据，运算其实不是门槛，门槛是数据交互的速度、通讯速度；主要瓶颈在通讯速度。芯片制程本身不是特别重要，芯片制程导致的热功耗之类，对运算效率来说也不是非常非常重要。但数据的快速传输，中国已经有一定的技术积累。我相信，在那个领域，NVIDIA那些厂商已经卷得很厉害了，对不对？快速数据传输这方面已经做得挺不错了。所以从这个角度讲，我觉得发展空间还是很大的，要结合智性生产力。当然，专利是个问题。

这些东西都是细枝末节的次要问题。我觉得原则和大方向是：对市场主体不能太放手，不能太让它们掌握大数据。市场主体有大模型，一定会有很多卡、很多算力，技术也更成熟，情况就是这样。我觉得宁可牺牲一定的发展速度，也要在性质上把它夯实、弄牢固。这是我的观点。否则将来果实成熟了，归谁就是一个问题。它本来是好事，是生产力发展，利国利民，对共产主义的伟大事业也是很好的一件事。所以这就是我的观点，就扯到这里。所以我是个本地部署党，本地党。
