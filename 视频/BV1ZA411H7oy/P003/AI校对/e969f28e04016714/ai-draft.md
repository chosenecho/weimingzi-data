我们现在来梳理一下这八条的两两组合，其中有对称的组合。对称的组合我之前已经讲过了：它的左边都是一样的，一共有四种。抄作业了，兄弟们：左边是一和四，都是 If there is one。那么结果是什么？The one is not all，the other are not all，结果都是 not all，即非全。这个对应就是一种在场形而上学；或者你也可以把它看成一种 proto fascism，一种男权主义，或者叫它 proto fascism。这个意思你们自己去找，是男性动物里面特有的。

第二种情况，这是对称组合，是两个命题组合到一块。第二种情况是 If one is：如果这个太一可以具体存在、可以显现出来，我们就可以讲 The one is，and the others are all，the others are all。他们就是整全的了，他们就整全了。

这种情况是什么呢？这是犹太主义，也就是恐犹主义。恐犹主义所说的，就是这种恐惧，即对“犹太”（Jew）的恐惧。有了这种恐惧，它可以解释一切；而且它是作为一个鬼魅般的太一存在在那里。这种东西看上去好像是纳粹主义，是一种很粗陋的东西，其实它是一种神秘主义，一种非常强的神秘主义。

这种神秘主义，我当年思考的时候把它理解成一种去性化了的斯宾诺莎主义。所以我觉得，斯宾诺莎的理论里面包含了恐犹主义的一个内核。斯宾诺莎本人是犹太人。这个东西实际上也可以被理解成上帝的自我凝视，在斯宾诺莎那里就是上帝的自我意识，是一种鬼魅般的存在，是上帝的永恒的自我意识。这个东西可以理解成一种彻底去性化了的男性主义：彻底去性化，以至于他认为自己所追求的伦理目标本身就代替了女性性，代替了那种女性性。

这里面的上帝不是一个蹩脚上帝；这里面的这个“万”，如果它是个上帝，它就是一个全能、同时又极度可怕、极度可怖的上帝。它的极度可怖也就是极度宁静，是斯宾诺莎那里极度宁静的上帝。这个上帝为了安抚他，会变成 the others，就变成自然神论。所以我认为，神秘主义发展到自然神论，实际上是发展到高峰、发展到极致，发展到斯宾诺莎这种静谧主义的自我直观，也就是上帝的自我直观。

下一个是 If one is not。如果我们拒绝斯宾诺莎这种诱惑，说太一不存在，并没有一个具体存在作为太一的对应物，我们就会得到 The one is all，and the others are all。我们同样拒绝太一的存在，不让它主宰一切；或者认为太一是一个否定性的存在，是一种生发性的力量（becoming）。这个时候，这个一就是全部，他者也是全部。这可以看成克尔凯郭尔主义（Kierkegaard）。在他那里，The one is all，the others are all，它们形成一种短路，对应着信仰与怀疑、独神怀疑同时存在，并且都达到极致；这个时候才是所谓的宗教阶段。

懂一点克尔凯郭尔的人自然懂这里说的是什么意思。这个时候，太一是一种生发性的力量，是一种否定性的力量，是在事物的边缘向外生长、展开、张开的力量；但它自己不具有自性，不具有自我同一性。所以这种东西构造了一切；但反过来说，它构造了一切，又只能使不是它的那些东西占据整个场域。虽然这是 the one，你没有发现这前后逻辑矛盾吗？The one is not。太一是一种生发性的力量，但它不能直接在场；后面又说 The one is all。如果我们用逻辑学而不是形而上学去理解，这他妈的就是放屁：The one is not，The one is all。

所以这个时候，你要看到这种短路：all 等于 not，也等于 becoming，等于生发的那种力量。这个全部是一种动态的全部，是一种否定性的、不停超越性的全部，是超越性的力量。所以它不停生成：从 being、从存在当中不停生成出一种力量，从 is 上面不停生成出一个 not，生成 not is 的东西。它是这样一种力量。这样你就可以理解：The one is all，它存在为 all，存在为一切；这个 one 本身不存在，但它能够存在为一切，可以 become everything。它可以存在为一切，但自己是不存在的，它生发出这一切，这是一种存在论上的生发。

然后 The others are，其他那些东西存在，也就是所有他者存在。这个 one 本身是掩藏起来的，没办法被直接把握。这种存在主义就是克尔凯郭尔的存在主义，是存在主义本身、原汁原味的存在主义；不是后来海德格尔把主体性维度塞进去的那种，不是一种形而上学的、不是很标准的存在主义。这种立场可以这样理解。

我现在在想，之前我说斯宾诺莎是彻底去性化的，它到底是去性化的还是超性化的呢？这应该是斯宾诺莎那种去性化，而这里的克尔凯郭尔主义，看上去又像一种男权主义，其实应该是一种女性主义的立场。克尔凯郭尔主义应该是一种女性主义立场，即 becoming 要高于 being，not being 或 be not，以“非”、以一种不存在为目的来存在，大于存在本身，优先于存在本身。在本体论上，太一是没有办法现身的，它永远掩藏在那边，是一种力量，永远使得别的东西能够借助它的力量生长出来。这玩意儿也就是存在者存在；存在者存在就是这个意思，就是 The others are all：它是借由这个 one、借由这个不存在的 one 的力量，一种无的力量生发出来的。

那么它是男性的还是女性的呢？它应该是一种女性主义，因为它没有直接说这个，但它是一种前反思的女性主义。我感觉它是一种比较少女的女性主义，还尚未进入菲勒斯性化秩序，是一种无知的女性，还天真地认为有一种生命力在那边涌现、生成出来。

最后一种，我们之前也讲了一个，现在看最后一个，这也是一个标准的女性化历程：If there is no one。如果 one 不存在，那么 The one is not all；The one is，and the others are not all，他们都一样，都是非全。菲勒斯这个玩意儿是个蹩脚的菲勒斯；主人能指是废物不行——这男人这么不行啊，你还算男人吗？他虽然嘴巴上这样说，但是 The others are not all 也一样：女性性本身会变成乱七八糟的东西，但还没有办法构成整体，无法构成整体。所以这两个东西有一种并列关系，一种蛮纠结的并列关系。

这两个 not all，当然也可以看成都是一种开放性的 not all。但关键问题在于，它产生了一个对称结构：这个 one 和这个 others 都互相变成 not all。这个非全就“尾”了，这个 others 也“尾”了，就是那种多元主义。这个时候就会产生一种多元主义幻想，因为这个女性已经是带引号的开放性，已经进入性化秩序、进入女性性化秩序里面的女性。所以如果这个时候把这两个东西看成是对称的（symmetry），就会导致两个 M；两个拼起来等于一，就会导致这个 one 加上这个 others 等于 all。

这个等式不成立；如果它成立，就会变成一种比较妥协的、资本主义式的多元主义，也就是在一种蹩脚的性秩序下、蹩脚的主导性秩序下——male and female 主导性秩序之下——的一种 LGBT plus 多元主义。这种多元主义是错的，因为它有一种幻想，幻想这两个可以拼起来。其实不仅它们不能拼起来，而且它们这个 not all 不是同一种 not all：这里的 not all 背后是一种构成性的 not all，而这里的 not all 不是同一种 not all。

这里的 not all 是一种“more than failures”的结构，也就是“failures is more than the……”。这个符号仍然能起作用，因为它会被想象成“failures is more than the……”。但这里的 not all 是说：sexualities are always not enough，not authentic enough。它们总是不够，总是不够。这边总是多，总是一个多；而 sexuality、各种性活动、各种性方式总是 not enough，总是不够本真，不能配得上这个东西本身。所以它就会陷入一种收集癖式的多元主义。

但恰恰是在这个东西上面，笛卡尔主义才产生出来。笛卡尔主义中的上帝是一个不那么厉害、有点蹩脚的上帝。然后在这个第四个分支上，才慢慢产生观念论。观念论这种东西没有那么严格。所以这四种对称组合形成了四种哲学史上的东西。然后我们再看不对称的组合。

非对称组合，比如一和二组合起来。一加二就是：一是“if there is one, the one is not all”，二是“if one is the one is all”。这两个拼起来就是 Christianity，也就是基督教。第一个是旧约，第二个是新约，还是这样一个关系。所以它的集大成者是 Gaulian。

它的本体论预设是：场域是整全的。《精神现象学》一开始预设场域是整全的，后来慢慢推演到最后。但实际上，从观念论的角度来讲，黑格尔仍然认为场域是整全的，因为他还是一个唯心主义者，还是一个 idealist。归根结底，黑格尔的辩证法是 idealist 的。所以这个东西看上去很像“if one is the one is all”，这里的 one 就是绝对精神 Geist。

一和二可以拼起来；还有一和六也可以拼起来。一是“if there is one, the one is not all”，二是“if there is no one, the one is not all”。答案呼之欲出，它是海德格尔主义（Heideggerian）。为什么？前面这一部分指的是对存在的遗忘，指的就是人类的形而上学历史，海德格尔对此进行了描述；后面这一部分是他的存在主义，他自己的哲学，就是思。前面这一部分代表哲学，下面部分代表思或者诗的领域，这两个拼起来才是海德格尔主义。光有一部分的话，你顶多能切进到克尔凯郭尔主义。所以这种存在主义是海德格尔的存在主义，可以看成是一种历史性的存在主义，historical existentialism。还有，哦，是第六个，不是第二个，是第六个，一和六拼起来。我当时拼了好多，不管了；我还有其他，你们自己拼吧。我夸下海口说六十四个，现在拼不下去了。我能给你们讲的就差不多。反正这是一种游戏，这个游戏可以一直玩下去，因为它现在只具有一些很有限的维度。这个游戏里面，这个 if 代表主体性。

这个游戏里，there 代表存在论或本体论，或者符号系统；is 代表存在，代表具体的实存；all 代表整全、全体；one 代表一个整全。这里整全和全部不是一个意思：整全指的是它的一致性，代表一致性。我一直会把它说成整全，可能是 coherent 的意思，有可能又拼错了，不管了。not all 代表一种开放性，或者有限性。not 或 no 可能代表一种不在场，或者否定性，或者自我被灭、自我冲突、内在冲突、内在的自我冲突。

这些要素加起来，可以把前面的八个命题进行八乘八的重新组合，得到六十四种。这里面比较奇怪的是它自己交叠的情况，还有互相换位置的情况，所以可能还要除以二，我不是太确定。具体操作起来、运思起来，举个例子，比如海德格尔这种历史性的存在主义，如果把它顺序倒置一下，从这里走，反倒走向那里，那我们可以说它是一种什么主义呢？这个时候就有意思了。如果我们把海德格尔颠倒过来，就要你开动脑筋了。我把这个问题留给读者、听众，让你们自己去思考。我不想剥夺大家思考的乐趣，或者说我现在已经疲倦了，懒得去考虑这种形而上学问题了，已经头疼痛苦。这个玩意儿……所以说，经验哲学在柏拉图那里、在《巴门尼德篇》里面，能玩的游戏太多了。

《巴门尼德篇》里能玩的东西太多了，可以建构一个神学大厦、一个神学体系出来。因为他们那个年代都把 one 叫作上帝，普罗提诺主义、新柏拉图主义都说 the one is God itself。好像不能用 him，而要用另一个词。

不管了，反正齐泽克（Žižek）在他好几本书里都会提到，柏拉图也曾是一个激进的形而上学探索者，他探索的就是这种东西。因为他在面对这些开放的选项——甚至可以说无数选项，因为可以无限堆叠——面前，这个家伙怂了，柏拉图怂了。因为这些开出来的无数选项都是主体性开解出来的，是主体自由、主体的自由维度开解出来的。所以它背后包含了一个激进的假设：如果这个世界根本没有形而上学结构，如果它根本意义上是开放的，取决于主体的自由选择——不是自由选择，而是主体自由的一种展开、主体内在规定性的展开——那么这就意味着这个世界是一个非常 subjectivized、非常主体化的世界。或者说，与其说是主体化的，不如说这个世界本身是活的。它并不是被我的意识所控制，不是；它自己内部有一种斗争。这种开放性是柏拉图瞥见了一瞥、自己把它写出来的，把无数种可能性写了出来。

但他后来又把这种开放性闭合了，在《蒂迈欧篇》里又把它闭合了，变成另一种属性和属性之间的堆叠。在《蒂迈欧篇》里，我们又看到另外一种看上去很精巧、但实际上比之前讲的结构要封闭得多、思维上要怯懦得多的本体论，另一种形而上学。这种形而上学通常会被说成是柏拉图受到毕达哥拉斯的影响，跳出了他之前理念论的窠臼。但实际上，《蒂迈欧篇》这里已经是一个二流货了，已经是二流货色了。只有在《巴门尼德篇》里，柏拉图才是最厉害、最强、最勇敢的，但他那个勇气只持续了一刹那，毕竟他不是一个现代人。

他不敢去思考那么一个混乱的、充满无限可能性的世界。但在当下，我们现代的人类要敢于去思考这样一个世界。这个世界，这个游戏很累，很累。

好的，我觉得我们也是用尽了浑身的力气，才搞了这么一通。通过这种方式，我们可以把六十四种形而上学立场推出来，甚至其中有些是形而上学不同范式的转变和变化。

哲学，我跟你讲，其实跟干苦力没有什么差别：很痛苦，好累啊，哲学就跟干苦力一样。好的，我们讲完了，就这样，拜拜。
