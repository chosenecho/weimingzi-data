我们今天要讲“主义主义”的结构主义最后一个部分，3\-4\-1\-4，代表人物是福柯。这个体系我把它命名为 state mental discursivism。

这个术语是多义性的，其实可以翻译成“陈述的话语主义”。这时我们会看到，3\-4 的四个东西，我都是用一个形容词加上一个 ism 来命名。

第一个是列维\-斯特劳斯，我把它叫作结构的人本主义，或者 structural 人本主义，因为他在结构主义上确实有突破，即那个 man 的悬浮能指。在列维\-斯特劳斯那里，重要的是话语，也就是符号学、结构主义的基本单元；结构主义的基本单元是什么？神话。当然我不能说“神话主义”不对，但它归根结底是破解神话的，所以叫人类学主义、人本主义。

第二个是拉康，叫作隐喻的象征主义。它的突破在于让一种张力显现出来，也就是纵深性。结构主义要获得纵深性，先不谈时间性，先要谈纵深性，就是要有真正的主体出来：一个镜像的自我和一个在符号秩序里的主体之间形成纵深，形成一种隐喻关系；镜像实际上是用来隐喻那个东西的。早期拉康那里，隐喻是更重要的问题意识；到晚期则是转喻占优先性，因为隐喻的问题已经解决掉了，他自己有底层符号学的辩证机制，所以隐喻、纵深性的问题已经解决。因此我把它叫作象征主义，就是 symbol，目的是走向象征界，象征才有纵深。

走向象征界。第三个是昨天讲的罗兰·巴特，他叫作叙事主义。他的结构主义符号学分析的基本单元是叙事、叙事活动。你们现在觉得第二个好像隐喻性的象征主义，就会想到那个家伙——那个喜欢用几个字母给人格做分类的家伙，那个名字都不配被我记住的家伙。那个家伙完全没有抵达结构主义哲学，也就是哲学意义上的结构主义阶段，所以我觉得他不配，没什么好讨论的。罗兰·巴特这里则是分类学，是分类性的分类学。他做不出真正的纵深怎么办？他就搞出部分和整体这种关系，搞出很多模棱两可的分类学，在文论里搞一堆模棱两可的符码分类，分好几类，那本书里面又分好几类。这些东西都是炫技，没有任何意义；里面没有真正的直面，没有严肃的哲学意识。但他的泛叙事化——把整个世界所有的文本、所有现象、所有体验、所有意识形态、所有政治现象、经济现实都泛叙事学化——在哲学上是有贡献的，所以我要把他提出来。

今天讲福柯，我把他叫作 state mental discursivism。他的结构主义、符号学的基本单元就是话语，基本单元是话语；只有在话语那里才可以加以分析，结构分析的基本单元是话语。

更进一步是 statement。statement 是陈述；但在福柯那里，它跟政治权力有关，跟 state（城邦）有关，跟共同体有关。所以我把这个词用了一个双关，甚至可以说是三关：state 有陈述、设立、说出来、表达出来的意思，也有状态的意思，代表一种稳定的状态，一个共识性的局势，即共识性结构、符号系统里的一个局势、一个状态；这其实也是福柯所设想的政治性关联体的基本态势，也就是权力网络的基本态势。state 还可以指国家。后面加上 mental，把 statement 变成 statemental，也是双关。

mental 在这里有两层意思：一层是心智正常、心智健全；另一层是发疯的，mentally sick。英语里说 his mental，有时就是他精神有问题。所以 state mental 一方面指 state 认为自己肯定是心智健全的——爱欲与文明嘛，我是文明，我肯定是正常的；另一方面，mental 这个词也说明他为什么如此关心 mental：为什么这个 state 要专门给那些 mentally sick 的人设置一个位置呢？

这特别体现在福柯对十九世纪之后现代文明的考察。十九世纪的现代工业文明，特别是二战之后，大家认识到社会是一个有机体；尤其是法国的社会学传统，就是有机体。我们前面都讲过，法国的社会学传统是哪几个人？孔德、斯宾塞这些人。我的工作记忆比较差，你可以去看我前面讲的“二二字头”那一期，我都讲过。从实证主义运动、社会学的实证主义运动开始，十九世纪大家就意识到社会是一个有机体。这个有机体会有它的剩余，也就是它有它的排泄物；当时的知识界或者统治者已经意识到，它的剩余就是那些 mentally sick 的人、精神失常者。后来不再把他们看成一般病人或一般罪犯，不把他们放到一块去，而是专门隔离出来，并且免除他们的刑事责任和民事义务。这样他们就变成了现代法治体系和现代权利关系网络、人际权利关系网络、权利义务关系网络的一个剩余；这个剩余支撑着这个有机体，它是这个有机体的剩余。

所以 state mental 在这里表示 state 和 mental 之间有一个非常紧密的关系，这也是福柯分析出来的。我明确告诉你，这是福柯对知识型（episteme）的分析。episteme 是这样拼的吗？我可能拼错，我的记忆力很差。哦，是的，episteme，知识型。

福柯对知识型以及知识考古学有很多重要贡献。archive 是馆藏、记载，archaeology 就是考古学；知识考古学是在 archive 这个术语、记载之上建立的。知识考古学并不是去考某个具体对象，而是要把知识型考掘出来，通过发掘学术史来做——因为留存下来的材料主要就是学术史材料。从文艺复兴开始，学术活动和学术史留下大量文本材料，这些材料可以进行知识考古学；中世纪之前多是残篇手稿，文本量不足以支撑一个符号学体系。知识考古学是福柯成熟的话语主义的实现方式，它考到最底层就是 statement，即陈述，是不同学科的理论性陈述。这些材料从文艺复兴、启蒙运动以来大量存在，藏在老欧洲的图书馆里。

美国没有这些材料，可能英国有；所以能干这件事的就是老欧洲。福柯这套知识考古学为什么能有一席之地？因为战后他代表了法国世界的尊严，美国人干不了这事儿。你美国人在二手书摊上买不到十七世纪出版的书，十八世纪的书也买不到几本；或者说十八世纪的时候，你美国有什么？啥都没有。那种用罗马字母印刷的、特别漂亮的、用拉丁文写的书，老实说我都看不懂；或者用罗马化的字母，上面写的可能是德文，也可能是法语。那些书字母特别漂亮，每一本都是金边的；也有红边的，红边的是宗教性的。整本书特别漂亮，我见过，差点买，一看超贵，几十欧、上百欧，一本上千欧都有可能。这种活儿，你可以看成是老欧洲的一项行活。

所以福柯在学界的面目，并不是你们所想的那么激进，他没有那么激进。这家伙不激进。他在法国哲学圈子里是很正的一种研究，他做的是学术史的重新梳理，或者科学史、文化史的梳理；这个活儿是很正统的活儿，基本上是那种——我在想是谁——迪尔泰这种人可能会做。他很年轻，但他干的活儿好像五六十岁的人干的。不过他只分析了一小部分，知识考古学里只分析了文艺复兴以来的部分，可能从十五世纪开始，涉及十五、十六、十七、十八、十九世纪，到二十世纪；后面就是天下大乱，走向战后秩序。知识考古学考的是“骨”，他通过知识考古学也有断代。

福柯的知识考古学对知识史、话语史做了断代，分成三个阶段：文艺复兴时期，十七到十八世纪的启蒙运动时期，以及十九世纪以后。十九世纪以后才是我们所谓的真正现代哲学。简单来讲，文艺复兴时期的主导原则是相似性。

相似性思维，说白了就是瞎说一气。那个时代的人没那么聪明，逻辑思维能力没那么强，笛卡尔还没出世，笛卡尔那种把世界符指化、坐标系化的把握还没有成为时代精神。因此，文艺复兴时期的知识型是通过相似性原则（resemblance）来维持的：在能指和所指、词和物之间，是一个三元知识关系——词、物，以及相似性。相似性很含混、说不清，但它也是一种知识型，是在结构中起作用的规律性、规则性，是一种张力。

到了十七、十八世纪的启蒙运动时期，更强调机械性原则。这里起主导的知识型（episteme）就相当于范式。

它相当于科学范式，但不像库恩的范式那样。福柯的知识型比范式要彻底得多、根本得多，比库恩的科学范式、范式革命要彻底得多、根本得多。因为他的知识型是结构主义的，由底层符号学支撑，是由 statement（陈述）构成的；statement 陈述是它的基本单元。

statement 陈述，比如经济学陈述。一则经济学陈述，我举个例子：“联准会降准会使得全球经济有过热的风险。”这是一个经济学陈述。

这一则陈述由许多同样的陈述支撑，但陈述和陈述之间也会有冲突。有冲突的地方，就能让结构主义分析师从话语当中看出：应当是由陈述构成话语，由陈述构成某种学科话语；然后在所有话语中间，怎么看到话语的形式？通过陈述之间相互的矛盾、冲突和相互支撑。

这些陈述在一个学科史里，比如同一时期的经济学，肯定是相互支撑、相互关联的。但它会有矛盾点、冲突点，会有症状。这些症状就暴露出它隐藏的形式是什么。把这些隐藏的形式抽象出来、把握到，它就变成一种话语。话语有各式各样：经济学话语、精神分析话语、心理学话语、政治话语、性的话语、粗俗的性话语、艺术话语等等。

这些话语之间又会有冲突，也会有相似性，比如结构的共通点，但又会有冲突。通过结构主义分析，可以把握到它们内部共同的结构，从而把握到这个知识型，把握到一个时代的知识型。与其说是一个时代的知识型，不如反过来说：是知识型塑造出表现为一个时代的东西，知识型更源初。知识型是所有社会话语底层结构的一种共性，或者说一种张力、一种态势、一种基本运动方式；也可以说是基本的发生学，是话语本身的一种本体论方式。

所以，是知识型反过来决定一个时代；这个时代里所有人的思想、心灵、精神等等，都由知识型决定，由话语以及不同话语的相互关联形成的知识型来决定人。在福柯那里，首先神肯定 goodbye 了——这是结构主义，不可能有大他者；其次人也 goodbye 了，没有主体，一个时代里不存在什么主体性的迸发、什么精神，这一切都由知识型本身决定。

一个时代对应一个知识型，但归根到底是知识型决定时代。

这只是从“知”的层面来说的。回过来看，十七、十八世纪是机械性原则占主导，特别讲究逻辑和线性序列。线性序列构成树状网格、机械性的网格，也就是矩阵，或者我们所说的坐标系、坐标系网格。这种坐标系网格、线性序列主宰了十七、十八世纪绝大部分的思维。但福柯这里的分析其实有误：观念论运动并不服从这种机械性原则。当然，我们在康德身上看到很大的影子，但那已经是十九世纪、一八几几年了。也可以说德国在十八世纪、一七几几年还没什么文化，所以这些东西被忽视了。不管怎样，福柯说十七、十八世纪由笛卡尔、英法经验主义和理性主义主导，逻辑机械性原则占主导，这是对的。

到了十九世纪，则是有机体原则。这正是福柯离谱的地方。他没有看到，在观念论运动、后观念论里面，并不是搞有机体。不管这些，反正福柯科班好像是学精神病理学出身的，他学的东西也很多，什么都要学一学；但他对哲学史上的精华领会不深刻，所以认为十九世纪的时代精神，或者他所谓知识型，是有机体原则。

有机体原则就是追求事物之间的本质性关联，彼此支撑，但其中也会有短路；它是有机性的，会有一个系统、一种体系化，会有一个至高原则，或者一个原初的辩证法机制作为动力学机制，让这个体系不停自我更新、活着。它让知识结构、知识框架不停活着、自我更新。

所以我说，福柯对十九世纪时代精神的领会不深刻。他没有看到，观念论里蕴藏着一个颠覆性的力量。你这样分阶段是有问题的，因为十九世纪最重要的思想运动就是观念论运动。后来由存在学运动、存在论运动、现象学运动片面地继承了它；结构主义运动也继承自它，也靠科耶夫。老实说，真的靠科耶夫。

在有机体原则下，一切事物不再是逻辑性、线性的排列组合关系，而是差异性的、他者性的、彼此支撑的关系；它会不停自我更新，会有矛盾和僵局，通过辩证法来克服，不断从较低形式走向更高形式。这种理解有点斯宾塞式的感觉。

知识考古学对应这三个时期。我们反过来看疯癫：在文艺复兴时期，疯子会被看成什么？是非正常人，但代表了某种神秘的、甚至神圣的维度。比如文艺复兴时期有些画家会疯掉——我记不清具体年份——不管怎样，在文艺复兴时期，疯人还是可以说圣语的。

到了启蒙运动、经验主义、理性主义时期，疯子会被看成什么？是非理性。人们会把犯罪、过度激情、性倒错和疯子都看成非理性，关到一块儿，也就是扣帽子，把疯子看成一般的非理性。

到了十九世纪以后，尤其是出现了精神分析和心理学运动以后，大家意识到，原来疯癫是有机体的剩余，是它的构成性例外，是它的丑闻。因此人们不再把精神失常的人和罪犯、其他边缘人士关在一起，而是单独把他们关起来，想要拼命治疗他们。通过治疗他们来反过来安慰自己：我的体系是对的，我的有机体没有问题。尤其是这些知识分子，还有社会权力、整个社会治理体系，都会拼命想通过安抚、治疗这些失常者，单独关起来、单独治疗，来证明自己具有时代上的前瞻性，能够治疗这个时代的病症。

这就有这么一个作用：疯子会被单独看待，被看成最特殊的剩余。这个最特殊的剩余在精神观念层面上支撑起最普遍的秩序，因为它是这个有机体的剩余。

再往后到后现代，也就是二十世纪某个年份之后，我们进入后现代。法国知识分子弃守现代性阵地，放弃了，因为他们看到了一次虚假的事件——一次由布尔乔亚、小布尔乔亚学生扮演出来的虚假事件。它不算事件，只是一次拙劣的丑闻。

然后这些知识分子就借坡下驴，弃守现代性阵地。所以从二十世纪七十年代开始，就进入所谓的后现代。在我看来，后现代实际上又回到前现代，可能回到十七、十八世纪，甚至在观念上回到十六世纪文艺复兴那个“蛇皮”状态。

这时我们来看他的场域论。其实这里也讲得差不多了；另一个东西是 micro power，我不知道能不能讲。这样写吧：左边写微观，右边写宏观。左边是微观网络，右边是宏观结构。

宏观结构可以说成是谱系学（genealogy），也就是宗谱、家谱的意思。微观网络的探查则通过话语分析（discursive）或陈述分析。微观网络结构里面会有冲突和失衡。

通过冲突，它的发生学机制是：要协调微观与宏观两者，得靠考古学。考古学协调两者，把微观话语当中的冲突、失衡发掘出来，发现它们隐藏的、埋在深处的规律或结构，然后慢慢导向一个宏观。主体就是考古。

在福柯那里，如果说主体性还有残余，主体就是一个考古学机制，我们把它叫作话语考古学机制。主体就意味着能够穿透。这种考古学机制是从具体、最浅层最表层的陈述和话语中的不一致性出发；主体通过这种不一致性、通过其中的冲突，抵达某种普遍形式。然后把这些普遍形式连缀起来，主体在获得这种普遍形式的时候就获得所谓的知识。众所周知，在福柯那里知识等于权力，知识就是权力；而主体就是记载，主体的唯一活动就是 archive。如果说福柯有某种主体性的话，他其实没有主体性；他不承认有主体这种东西，只承认只有话语，或者只有符号在运动。

这就是无我论，还不明白吗？在福柯那里，设立任何主体都被看成是一种权力，就是在发展某一种权力。这种姿态不是解构主义的，它就是结构主义的。我再强调一遍，不能说福柯这种姿态是解构主义；解构主义不是这样，解构主义连结构都不要了。这种姿态其实是很正统的结构主义的姿态。我不知道为什么有人会把福柯叫作解构主义者，或者叫后结构主义者；这不可能，福柯就是个结构主义者。结构主义本身并不是什么温文尔雅的东西；结构主义本身就很有颠覆性，只是很多人不懂。

我认为福柯把结构主义的精神继承到底了。尤其是他最后导向知识等于权力：知识就是对于普遍形式的一种记载，所以它比较具有穿透力。它的结构更为——你可以说这个结构更有压倒性的优势，或者更有穿透力，或者怎么样；因为它是普遍形式，所以这个结构更冠冕堂皇，或者更有效——我不知道该怎么描述。就是说，如果有一种主体性的话，在场域论上，它协调这两侧，协调微观结构、微观权力网络；我甚至要说，它协调微观权力网络和宏观结构。宏观的我们甚至可以说是 state 结构，宏观的 state 结构就是所有 statement 都服从的那些结构。
