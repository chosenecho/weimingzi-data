我们用计算机来举例，理解所谓的笛卡尔主义。比如你有一个 Windows 操作系统，你会怀疑：这里面所有的文件都是假的，怎么办？

你打开一个文件，它的标题本来叫某某写真，对吧？一打开，我靠，原来是马老师在跳舞，原来是马老师在练拳。怎么办？这就是被骗了，被管理员骗了。

笛卡尔主义的意思是说：虽然有可能发生这种情况——下面这个文件夹的名字、文件的名字和里面的东西对不上——但是你会发现，当你想把东西删掉，比如想把另外一个好的文件删掉的时候，嘣，它会弹出来一个“您没有管理员权限”，你没有管理员权限。所以这边让你重试或者取消，会弹出这么一个对话框。这个对话框就是所谓的真观念，也就是你有一个关于“真”的观念：如果你有权限，你就可以随意改动这些东西。也就是说，这些事物的存在有一种硬的实在性。比如得幻肢症的人，手可能没了，却会感到自己的手还在；

这就像某某写真文件里最后放的是马老师，或者打开一个空白文件，里面反而有东西。但问题是，你不能对每一个文件都进行这种操作，也不能任意决定你感知到的每一个内容；你还是能感知到一种硬的、实实在在的力量。就相当于在操作系统里，你要随意删改这些文件，甚至一些系统文件时，它会跳出来：嘣，你没有管理员权限，你没有管理员权限。这就意味着你脑子里有一个关于真的观念。这个真代表一种很硬的实在性，一种惰性，或者说一种意志性——一种来自他者的意志性。

简单来说，它会让你知道：原来有一个管理员存在，原来这台电脑不是我的私人电脑，不是我的 personal computer；原来这台电脑还有一个超级管理员存在。这个超级管理员就是所谓的上帝。既然有这个超级管理员存在，系统就会提示：“请联系管理员；想要删改，请联系管理员。”管理员的住址在梵蒂冈的某某某那里——系统知道管理员的住址。这个时候你就可以把这个设定连到整个基督教传统里去了：这个管理员就是上帝。

所以，笛卡尔主义的意思是：当你想任意篡改整个世界，想通过怀疑论消解整个世界的时候，你会撞到硬的实在性。这种硬的实在性体现为一个关于真的观念：在你的操作系统里会弹出这种通知——嘣，有管理员权限，你才能动这东西，否则你动不了这东西。

我们所说的真实，很真实嘛，就是：你要长得非常帅，那个女孩子才愿意加你微信；但你的脸就长那样，你要把它改掉，嘣，不好意思，你没有管理员权限。如果你有管理员权限，你要么把自己的脸改掉，要么把那个女孩子的审美改掉，都可以。那就是真，就是真实，因为它是一种他者，是一种意志性很强的东西。你要改的话，请联系这个管理员；但联系方式可能因为时间太久，管理员已经死了。所以“上帝死了”的意思就是：这个管理员已经很久不更新这个操作系统了，也不管了。这台电脑，你竟然还在用老早之前的 Windows XP 老系统，这管理员早就改行，不知道去干嘛了。这是理解笛卡尔主义的一种方式。

我们还可以用另一种方式理解笛卡尔主义，就是用梦境作比喻。我们之前讲的 A、B、C、D、E，其实可以把这些字母换成：A 是“人间如梦”，B 是“一切都是假的”，也就是人间如梦，整个世界就像梦一样。B 的意思是，除非我们知道“醒”，知道什么叫醒，否则就无法讨论梦，也没法说梦怎么样。

C 就是：这种“醒”超越一切梦，有一种清醒状态超越一切梦。D 是：这个超越一切梦境的“醒”，在一切梦境里面仍然保持清醒，自如地在里面运作。人间如梦，我们会觉得人间恍如一场大梦，但在这个梦里面有一样东西一直清醒，一直非常冷酷无情，它不会随意发生变动。那么这个“醒”就是命运；你要找到对应：这个“醒”就是命运。人间如梦，但命运除外；命运是使得人间如梦的那个力量，这个“醒”就是所谓的命运。命运本身不做梦，命运这种力量不做梦。

在西方基督教传统里，命运会被人格化，就是上帝、上帝的意志；但在中国，命运不会被人格化，命运会被看成一种偶然，有的时候叫“缘”，或者叫“业力”。命运不做梦，它残忍地让一切都如梦，让一切都像梦一样。命运是这种超越性的力量，是一个例外。这样你就能理解笛卡尔主义的意思了：你可以认为人间如梦，一切都是梦；但你再要怀疑，最后会发现命运本身是没办法怀疑的。“人间如梦”大部分是这个人面对命运的一种慨叹，是对命运的一种慨叹。

在中国语境里就是这样：命运弄人，命运弄人，人间如梦，但命运弄人。这个命运就是上帝。除非你意识到有命运的存在，否则你不会体验到人间如梦，不会体验到那种如痴如梦的感觉。你最后要慨叹一句“人间如梦”。这个时候你差不多已经醒来了，因为你看到了命运，看到了所谓的命运。这是第二种笛卡尔主义，它是一种东方化的笛卡尔主义，或者我叫它苏轼的那种“苏轼主义”，跟苏轼相关。苏轼就是代表人物：“人间如梦，一樽还酹江月。”我会再做一个视频，讲一下梦跟清醒之间的关系，那会涉及一点拉康，所以我在这里就不展开了。

第三个比喻是爱情的比喻。如何用爱情的比喻理解笛卡尔主义？爱情的比喻就是单相思，笛卡尔式的爱情就是单相思。笛卡尔本人跟那个什么公主还是女王之间的关系怪怪的，你可以自己去了解。他就是说，爱情就是：我心里面有一种对你的爱，莫名其妙地有一种。那么这个爱的观念一定来自于你，因为这个爱里面包含一种相对关系。或者说，爱的话，因为怀疑论者肯定——我确定我自己是不可爱的。单相思的人往往会有这种想法，这很重要：我确定我自己是不可爱的，所以我心里面对你的爱的这个观念肯定不是来自于我，了解吗？

所以这个爱肯定不来自于我。那么它来自于谁呢？所以我心中对你的爱肯定来自于你。所以单相思的人就是拼了命要去向对方证明，或者说要让对方告诉他这个爱从哪里来、从何而来。对方会很懵逼，因为这个爱对于对方来说是一个他没有的东西：这个爱不是我给你的。所以单相思的人去追那个自己单相思的对象，就会逼迫对方给出一个他自己没有的东西；他被逼着要给出一个自己没有的东西，这就会逼迫对方给出一个他没有的、自己也没有的东西。

这就是标准的笛卡尔主义式爱。笛卡尔主义式爱就是：我莫名其妙地会爱上这个人，但我又能确定我自己不可爱。但实际上，笛卡尔式的单相思很容易就可以克服。它很容易变成所谓痴情，也很容易克服，就是要从这个环节入手：我确定自己是不可爱的。你要多一点自恋，就能克服单相思。你要确定：这种爱他的、不可救药的力量，这种内在的力量和驱动力，不是来自于那个被爱的对象，而是来自于你自己，来自于你自己内部的结构性失衡。

所以从爱情的角度说，如果你能理解这种单相思：我莫名其妙地对那个人特别敏感，他的什么消息，只要他在场，我心跳就快得不得了，什么乱七八糟的。你就会认为这个爱一定来自于对方，或者是他施加的：他的存在施加了一种非常强大的力量，精神力量、情感力量。那你就能理解笛卡尔。笛卡尔的意思就是：我心里面有一个关于真的观念，这个真的观念在我这种人间如梦、一切都是幻想和幻觉的主体世界里面是不可能存在的，它只能来自于一个超越性的上帝，一个更厉害的上帝。就像系统弹出来一个“你没有管理员权限”，所以肯定有一个超级管理员在那边，他就是上帝。

既然有个超级管理员在那边，而且他愿意在我脑子里面注入这么一个观念，所以他至少肯定不会欺骗我，对吧？这不就是说：这个人能够让我感受到绝对的爱，所以这个人也是绝对真实、绝对美好的。你在单相思的时候就会这样：他绝对不会骗我，绝对就不会骗我，因为他让我感受到这个爱本身是绝对的，是没有任何瑕疵的，是完美的。然后我只要得到他的回应，只要他也爱我，我靠，我就得到了一切。只要上帝、管理员——超级管理员——说“好，就让你来做 GM”，就让你来做 GM，赐予你这个二级管理员权限，那我就爽了。差不多这种单相思也是这样：只要那个绝对美好的人也能爱我，他也能赐予我一个四亿级的权限，那我人生所有问题就解决了。

所以，笛卡尔式的单相思和笛卡尔主义的怀疑论实际上是一脉相承的。这种单相思里面实际上包含着非常炽烈的一种怀疑的欲望：这个玩意不可能是从我内在萌生出来的。那只有一种情况：就是他也爱我；或者说，他就是注定的那个人。我们差不多就能理解什么叫笛卡尔主义了。下面我们就先这样吧，待会儿我会讲斯宾诺莎。
