今天我们来讲海德格尔的《存在与时间》这本书：它为什么没写完？

这个问题，齐泽克在《敏感的主体》第一章讨论过。

我最近看了他这本书。我小时候也是读海德格尔长大的，读的就是《存在与时间》。这本书虽然没写完，但其中一些问题其实都得到了相对的回答。

也就是说，海德格尔自己认为他把这件事完成了；但齐泽克在《敏感的主体》里指出，《存在与时间》所爆发出的那种激进革命性，其实被海德格尔自己的语言学转向遮盖了。语言学转向叫 turn。

在德语里，这个 turn 叫作“开合”，我不知道念得对不对。

海德格尔发生语言学转向之后，实际上背叛了自己在《存在与时间》里获得的那种最极端的革命性，也就是那种主体性革命性。这是齐泽克的观点。

那我们来看《存在与时间》。这本书实际上没有完成；它原来的写作计划分为两部分。

第一部分其实要分为三部分：首先是从日常生活中如何获得一个此在的存在，把这个此在的存在暴露出来，实际上就是奠定一种存在主义的分析方式，即描述日常生活的分析方式。所以他搞了一些“在手”“上手”“烦”之类乱七八糟的东西。熊伟在翻译这本书的时候，就觉得海德格尔这个人太跳了，用了好多黑格尔或康德那里没出现过的概念。其实他的东西不能算范式转换，这有点文化学研究；他用了一些新的概念，其实是用了一个新的符号学矩阵。

比如有这些例子，我不一一举了，你们感兴趣的可以自己去看。我还是把这个矩阵画一下吧：本真方面、非本真方面。本真的一种是上手状态，上手状态是本真的；非本真的一种是在手状态，现成在手、现成性，是非本真的。还有一种向死而生是本真的；那个沉沦就是随波逐流，简单说就是随波逐流，它是非本真的，这个就是变成所谓的 das Man，也就是常人。陈嘉映的版本把 das Man 这个术语翻译成“常人”。上手状态和沉沦这两个，是融为一体、与物融合的状态，是一种入世的状态；另外两个——在手状态和向死而生——则是出世的状态，与对象分离开来。

所以海德格尔基本上给出了这么一个矩阵，这是他的第一部分。其实其中有些对本真性的批判，实际上是在 part two 里才写的；不，应该是在卷一、卷二、卷三。其实卷三是多余的，本来不在他原来的写作计划里，是他后来为了凑字数写的。这本书是我十几年前读的，记得不那么清楚了。卷二应该是这样：卷一是准备工作，卷二是想在所谓存在论的基础上分析此在的存在。卷一是从日常生活当中获得了此在的存在，也就是获得了一些存在论的基本术语规范，或者一个套路；卷二则用这个套路进一步分析主体性的存在。

所以卷二是一个登峰造极的 subjectivism，广受争议，说它是主体主义的，因为卷二有点把整个世界的存在都放在此在的存在上面。

卷三则是从个体、从个体的向死而生走向一个群体，也就是所谓的 people、民族，并领受所谓的天命。卷三一开始并不在他的写作计划里。这是第一部分。

海德格尔这本书最后的情况是：在他原来设置的两部分写作计划里，他只完成了第一部分的卷一和卷二；他觉得篇幅不够，又把卷三添了进去。卷三基本上写的是：个体这种本真的存在、向死而生的本真存在，如何变成一种群体的本真存在，也就是克服卷一和卷二里出现的那种庸俗、庸庸碌碌的常人的生存状态。

那么，海德格尔的第二部分想写什么呢？第二部分他实际上也写了，但不是写在《存在与时间》这本书里，而是写在这两本书里：一本是“康德书”，即《康德与形而上学问题》，实际上是用他的存在论以及时间样态的分析来描述康德的哲学范式，主要是德国观念论；另一本是《现象学的基本问题》，里面也描述、讨论了其他几种时间样态，比如亚里士多德、笛卡尔的时间样态。

所以第二部分实际上是什么？海德格尔想探讨的是时间，把它作为存在问题的存在论问题，也就是存在论问题的先验视域（transcendental horizon）。他想讨论的是：在时间这样一个先验视域里，存在论有哪几种？

简单来讲，可以把它理解为我们之前一直说的操作系统版本更新史，也就是存在论的不同种类。它主要讲三个——其实可以说是四个，海德格尔本人认为是四个。

第一个是亚里士多德式的时间性；第二个是笛卡尔式的；第三个是康德式的；第四个是海德格尔本人的。谢林和黑格尔没有被算进来。

莱布尼茨、斯宾诺莎等人，他另外有书讨论，但他没有把其他人看作在时间的先验视域上有什么重大变化。他把这三个，包括他自己，看成是时间问题——时间性、时间样态的一个重大更新。比如可以这样理解：亚里士多德是 Windows 95，笛卡尔是 Windows 98，康德是 Windows 2000，到海德格尔这里是 Windows XP。

这个 ontological 是存在论，存在论的 problematicity，即存在论的问题性；它在这几个不同版本里发生了变化。发生变化的一个追溯性原因，就是时间在里面有不同的样态，也就是时间样态。

海德格尔本人的时间是一种绽出的时间性；亚里士多德、笛卡尔、康德那边都有不同的时间性。康德那边可能把时间性都空间化了，我记不清了。康德书，你们感兴趣的自己去读。

《存在与时间》原本第二部分的计划，是讨论时间性、时间样态，也就是不同意义上的时间性：它在不同的“操作系统”里，也就是在不同的存在论问题的先验视域里，你这个电脑里的时间函数是怎样的？

线性时间可能是亚里士多德和笛卡尔那边生成出来的。亚里士多德那边一开始有一种工具性的目的论时间；笛卡尔那边则是数学化的一种线性时间，而且登峰造极。到康德那边，时间更有一种空间化的倾向；特别是在牛顿那边，是一种空间化的时间。到海德格尔这里，他说自己要返璞归真，回到时间本身，把时间作为存在的一个视域、先验视域来加以分析。

那么在《存在与时间》这本书里，实际上，这本书虽然名叫《存在与时间》，却不包括时间——时间被换成了天命。所以这本书名不副实。

它名叫《存在与时间》，但只分析了存在问题的一部分，而且是一部分此在（Dasein）的问题；对时间性的讨论很有限，非常有限。书里讨论了一部分什么“到时”啊、什么“谋划”啊，还有一些乱七八糟的东西。那些东西在我看来不具有哲学上的精细性，只有文学创作的意义。

所以我觉得《存在与时间》这本书可以叫《存在与天命》，或者《存在与命运》；英文就是 Being and Destiny，你可以把它重新翻译。

齐泽克对这本书有一个批评，就是说海德格尔把重要的、困难的问题略掉了：第一部分里那些重要的、困难的问题被略掉了，最原始地阐释存在的事业，这个活他没干。在第一卷里，海德格尔很快就走向本真与非本真的二元对立。

海德格尔认为，克服这个本真与非本真二元对立的方法，就是从个人走向群体，实际上就是走向民族。这个民族中的个人要勇敢地向死而生；如果这个民族出现一个英雄，一个向死而生的英雄，那么其他个体就要向他学习，重复这个英雄个体的向死而生，然后去领受一种天命——存在之天命。

所以这个时候齐泽克认为，他这种做法遮蔽了先验主体性、先验主体主义的视域，也就是 transcendental subjectivity。

他把这个视域遮蔽掉了。他本来应该走到本真的个体之后，本真性本来应该变成一种历史性的创造力。对应到传统观念论，或者在康德哲学、观念论哲学里，这种创造力其实就叫先验想象力。

我们可以去看《纯粹理性批判》里的先验想象力，transcendental imagination。先验想象力是什么东西呢？比如你脑子里想三角形，三角形这个概念一定会让你头脑中浮现出一个三角形的 image；哪怕眼前并没有真正的三角形，也一定会浮出一个三角形 image。这就叫先验想象力，也就是你头脑里那些预制的函数、概念或者说函数。它不只是可以被调用、起作用，它不仅仅是一个函数，也可以变成一个 image、变成一个图像。也就是说，你的 CPU 不仅仅是 CPU——这里不该打岔——你的 CPU 不仅仅是 CPU，你的 CPU 是个 APU，简单理解吧，是带核显的。你不需要一个显卡；显卡意味着你还需要某个东西帮你来算。不是的，就是你的概念体系，你头脑里的语词、符号、概念体系，它自己能够图像化。想象力这个词，imagine、imagination，实际上就是图像化的意思，先验图像化能力。

再比如马：它在你脑子里不仅仅是一个声音，还是一个符号、一个集合、一个抽象集合，所有具体的马都放进去；同时你会隐约感受到那种马的形状就在眼前浮现出来。它不能算内视觉，你并没有看到具体的图片，但它是先验的一种图像化能力。其实在你快入睡的时候，你的内视觉、那个自我抑制的抑制功能，或者叫审查机制，变得比较弱、不起作用的时候，你嘴里说马，眼前就会浮现出具体的马的形象。这个时候就不是先验想象力了，这个时候想象力变成了一种经验性的、empirical 的，已经变成经验图像了。但我要说的是，先验想象力是能起作用的，特别是在审查机制、感官的自我抑制功能缺失或者松懈的时候：你调用符号系统、调用语词、调用符号，先验想象力立刻就会喷涌而出，使经验图像显现出来。你可以试一试：快入睡的时候，半睡不醒的那个状态，有人说这就是做梦，其实这不是做梦，你还是清醒的，你的符号学认同还是个清醒的状态，还是个自由的自我意识、清醒的自我意识。这个临界状态，我跟你们说一下。

那么齐泽克认为，这个缺失的讨论，就是本真个体与先验想象力之间的关系。本真个体就是做出抉择。

真正的本真抉择，并不是在 A、B、C、D、E 这些既定选项里挑一个；这些都不是本真的。真正的本真，是创造选项、创造新选项，是突破环境，并回溯性地把原本不存在的选项变成一个必然的选项，不仅让它成为与原有选项并列的一项，而且让它成为必然的选项。这种能力就是先验想象力。为什么说这种能力就是先验想象力？因为它就是把外部事物给视神经带来的神经冲动加以图像化的能力。比如红光波进入你的视网膜，最后要显现为一种红色。有什么东西规定红色应该长什么样吗？没有，只有先验想象力自己在规定什么是红色。红色光波按理说可能让你感到烫、痛、亮，或者别的什么，但唯有先验想象力这种无中生有的能力，能变出一个本来没有的东西，并把它注册进符号系统。

我用一个成语来告诉你，这叫“食髓知味”。一个东西是全新的，它到底是什么、是什么样子？可以理解成神经通路被打通了；但这种神经通路被打通到底是一种什么感受、什么样一种现实化？它要经验化成一种什么样的体验、一种什么样的客观状态？这是由先验想象力创造性地实现的。

所以，先验想象力就是这样一种创造性的能力，它就是海德格尔意义上的本真性、个体的本真性，是本真地做出抉择。这个抉择不是从既定选项中选。海德格尔后来在一些文章里批判了从既定选项里选的那种自由：那是一种病态的自由，是一种美式自由、消费主义的病态自由、消费主义的美式自由，海德格尔狠批这种自由。从已经既定的选项里选一个，那不叫自由。海德格尔认为，真正的自由是把桌子掀了，把既定选项全给你掀翻；是能够通过一种主体性的姿态和立场、一种抉择、一种向死而生，把自己内里那种创造性的、全新的力量绽放出来，这叫绽放。

这种东西并不是从内在中绽放——你可以说是从此在的，也就是主体的内在：它一方面从此在的内在绽放出来，同时其实就是从时间的未来中绽放。在海德格尔那里，主体的内在性、极度的内在性，与时间上的未来希望是同一的；它绽放出来，绽放出来的结果就好像本来就是这样、本来就有。也就是说，它是回溯性地篡改历史。通过这种力量——这是一种本体论的力量，这种力量就是神的力量，可以理解成一种创造性的、本体性的力量，创造之力——它是一种本体性的、本体论意义上的 ontological 事件。他后来把这个事件叫作“本有”，即回溯性地篡改了历史。

但这个东西，海德格尔是不敢直接面对的。齐泽克认为，海德格尔是个怂逼，不敢直接面对它。《存在与时间》讨论到这里，他没有细究，没有具体研究下去。先验想象力是康德在《纯粹理性批判》里讨论的，包括感性形式、先验想象力、先验辩证法、先验逻辑等。康德可以理解成一位老程序员，一位把 Windows 2000 系统研究得非常缜密的老程序员，或者一位面向对象的 Java 程序员。他研究先验想象力时犯了最多的错误，但他有一个研究范式在那边；这应该是康德的一个主题。

但问题是，海德格尔研究康德的时候，海氏完全视而不见；后来他自己也完全遮蔽了这一点。他认为这种主观主义——太把这种本体性的力量说成是主体内在的，把主体的内在性等同于时间的未来、未来绽出的未来——太主观主义，或者叫主体主义、太主体主义了。所以海德格尔后来批判康德时，基本上不再从这个维度进行思考。

那么在齐泽克看来，这个先验想象力的维度缺失，导致什么？导致海德格尔，导致海氏变成了纳粹。为什么？

因为海德格尔在这个意义上对群体本真性的追求，就是纳粹所追求的那种整个民族变成像古代智慧复兴一样的群体本真性，于是它就变成可疑的本真性了。如果海德格尔能够有先验想象力——历史没有给他这个机会——他就能导向共产主义。共产主义意味着，这个群体的本真性不再是像古代智慧复兴那样，回到古希腊、日耳曼人这些东西，也不是反技术主义、反现代性；它会导向一种群体的本真性，变成一种面向未来的想象力，想象一种在既定选项中不可能的革命的范式，也就是推翻资本主义、结束阶级社会，通过共产主义结束阶级社会。

纳粹虽然想回到古代的一种想象，回到古希腊那种原初的智慧，但它背后有深远的“存在之思”，有一种诗性的生活。所有这些东西其实都是在逃避，都是在逃。海德格尔在《存在与时间》里开启的先验想象力维度，就是主体通过自身内在的超越性，能够为历史提供答案。但这种能力被他躲避了，被海德格尔遮蔽了。海德格尔怂了，你可以把他理解成一个怂包。

此后很多年，晚期海德格尔转向之后，写阿那克西美尼、赫拉克利特之类的东西，也研究尼采、斯宾诺莎等一堆人，几乎研究了个遍。但他怂了，不敢去想象一种不可能的革命范式，也就是集体的想象力、集体的先验想象力。这其实就是列宁的国家革命说：在那个时代，共产主义可以在一个国家先成功，再通过这个国家输出革命，来实现全世界共产主义革命的胜利。这种选项在海德格尔这里就没有了。

所以齐泽克认为，《存在与时间》实际上有点类似于柏拉图在《巴门尼德斯篇》里提出的一个非常激进的立场。这个激进立场其实和海德格尔密切相关，就是所谓 ontological horizon，也就是本体论视域。你可以把它理解成操作系统。

这个操作系统，比如 Windows，可以有很多个版本；而且不仅有很多版本，还可以有 Windows、安卓、iOS、Java 等不同系统。当然，安卓是 Java 写的，甭管，我只是举个例子。所有这些系统，以及这边的 XP、98、2000，还有 Windows 10 之类的版本，是可以互相交叉的。

在《巴门尼德斯篇》里，这个激进的立场——你很怀疑这是不是柏拉图写出来的东西——表现为一种相对主义。但实际上它不是相对主义，而是很接近海德格尔所说的时间样态的变化，也就是时间性、时间样态的本真变化：这些原初的基本参数发生变化，可以生成不同的 ontological horizon，不同的操作系统版本，而且可以互相搭配。你里面的参数可能还有 1\.0、1\.5、2\.0，这些参数都可以互相搭配，是一些原初的参数。到时候我们可以去讲，《巴门尼德斯篇》里柏拉图到底是怎么玩这个游戏的。

但是在晚年的时候，柏拉图又怂了，变成一个神秘主义者。

海德格尔也是一样的。他年轻的时候接触到那种完全不确定、完全充满随机性和偶然性的创伤性现实，后来自己怂了，怂到去追本溯源，去讲存在的那种天命，讲诗人的艺术品如何敞开，然后呼唤、召唤这些东西的赠与和赏赐。于是他的主体变成了海德格尔式的主体，存在变成一种接受者；所谓“天”就是一种三重时间性的中间状态，一个接受者；他还有什么第四重时间性，乱七八糟，不管了。反正你可以把它当成一种挺有创意的东西。

其实我小时候读他那些东西，真的是被他唬住了。但现在年纪大了，我觉得他那一套除了给反动学阀擦脂抹粉之外，没什么实际用处。

那么大概就是这么一个线索：海德格尔为什么成为纳粹？因为他怂了。也可以说，纳粹这个意识形态本身就等于怂了：面对资本主义的基本矛盾，它不选择硬刚，不敢硬刚，不敢杀出一条血路，而是回归到前现代的本真性，回归到前现代的本真状态。这样一来，现代就会被把握成一种剩余，一种扰乱、会扰乱这种本真状态的剩余。

问题是，如果我们学过辩证法，就会知道这种本真状态其实是一个效果，是一个必须在被打破的时候才会显现的幻象、幻觉。本真状态是通过打破它才显现的；所谓的前现代本真状态根本不存在。如果你真正回到前现代本真状态，你会觉得那不过是凡俗而已。

恰恰是因为现代性的这种过剩、这种剩余、这种过度自由、过度否定性，这种否定性的剩余，现代人不敢面对它。现代人怂了，就会形成一个效果：我面对这个都怂了，那我还有一个东西可以逃到那边去，就是这个所谓的本真状态。是这个剩余本身具有的那种致命压力，使得这个本真状态看上去有很强大的力量，有很深沉地关怀、抚慰的力量。

就是因为你怂了，你逃避这个真正带有原初自由和不确定性的、那种冒险的冲动，你逃避它，所以你才能够幻想有一种前现代的本质。如果你不逃避它，这个玩意儿也就没有了。如果你真正回到前现代去过那种日子，这个玩意儿也就变成凡俗。所以这个本真状态是个幻想，是个效果。它是这个剩余本身在运行的时候，你逃避它，实际上就是被这个剩余追赶着，不停地绕着这个剩余本身的路径做循环运动：它不停地撵着你，你不停地逃，这时候就产生了一个效果，一个幻象化的效果，这个效果就是本真状态。

所以，海德格尔式的存在主义其实是一种失败的海德格尔式存在主义。当然，它不是人道主义；也不叫失败，准确说是一种怂了的 leftism，一种怂了的左翼理想。

这种左翼理想一旦怂了，就会走向极右翼，走向纳粹主义。你别看纳粹那么矬，纳粹背后会有那个很伟大的东西，就是海德格尔的信仰。你别看这个政权在搞大屠杀，在搞那些乱七八糟、很愚蠢的意识形态宣传，但它背后有一个更深的东西，你懂吗？就是海德格尔这些人信仰一个比较下三滥、矬的政权，他总要说这个政权背后有某种更深沉、更伟大的维度。

关键是这个维度并不存在。恰恰是因为它在表面上胡作非为、做很矬的事，你竟然还没有鱼死网破，这个符号系统竟然还能兜着它，这时候这种出乎意料就变成：难道它有天命？难道它有这种天命的加持？哪有个屁啊！没有，它就是在纯粹搞破坏而已。所以，海德格尔式的这种意识形态很容易被用来给反动政权擦脂抹粉。

所以，当你见到一个人以海解马，用海德格尔、特别是晚期海德格尔来解读马克思主义的时候，此人必右无疑。这个人是必右无疑的，就不要和他多说话了。

海德格尔晚期的思想确实有值得称道的地方，但他确实在本体论上有一些探索，也有一些失误。他对于那些张力、前现代的东西，或者说对于我们所说的、类似于柏拉图在《巴门尼德斯篇》里做的那些工作，有那样的探索，有那种游戏一样的探索。但是那些历史性的东西和他的基本政治立场是两码事。

你可以欣赏他那些闪转腾挪，就像你可以欣赏《意志的胜利》这部纪录片一样。但他背后的那个政治立场不值得称道，他的意识形态本身是有毒的，是很危险的，是极右翼的基督教原教旨主义的精致化，是极右翼。

我们去看德里达的《论精神》，它最后实际上把海德格尔的思想解构为了天主教思想，极右翼的天主教思想。你们自己感兴趣可以去看。所以德里达是一个左翼自由主义者，一个 liberal leftist，因此他对这种毒素的感知是很敏锐的。

但是，德里达和海德格尔其实都有一种对于 transcendental language、超语言、meta language 的迷之自信，这两个人其实惺惺相惜。他们都通过一种花招去追求某种超语言。他们两个都认为存在某种超语言，只不过是俗人、庸人没办法用工具理性、或者在场形而上学的那种思路去把握。但通过他们那种高级的反形而上学技术、精致的技艺，是可以玩到的；那种游戏、那种策略，是可以搞到这个超语言的。这个超语言背后其实是一种极右翼的意识形态。

我在这里说再多，还不如你自个儿去看；你看了之后，自己就会有自己的解答。好了，我今天就讲到这里。以海解马——你见到以海解马，此人必右，必右无疑。

而且，凡是以海解马的人，在最后关头肯定会捅自己人一大刀，换取他在知识分子圈或者说符号系统里的高官厚禄。这种人必不可接近。因为聪明人读到晚期海德格尔就知道，这玩意儿真的是哲学是哲学、政治是政治，要分开来看。那我们今天讲这么多。
