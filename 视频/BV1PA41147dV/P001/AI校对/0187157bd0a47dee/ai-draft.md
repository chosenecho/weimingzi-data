我们要讲的是两种主体，而不是两种主体性。我们日常生活中或一般语境里所把握到的主体，实际上并不满足于传统观念论，也不满足于西方哲学传统、笛卡尔所开创的现代哲学传统。

现在哲学里流行的主体有两种。第一种是我所说的、普通人理解的主体，或者说一般人类学研究或比较主流的认知主义研究里的主体；这些研究已经不再研究传统笛卡尔意义上的主体了。不是有所谓的“笛卡尔的谬误”吗？现在有一本书研究的主体叫 agent。

我个人比较把 agent 翻译成“能动者”。它还有特工、代理人、代理商的含义。比如特工 007 就是 agent zero zero seven；动因也是这个词，意思差不多。

为什么会提出这样一种主体呢？它实际上也是一种主体的样态，但人们已经不再把它叫主体了，因为传统笛卡尔意义上的主体就是专门的那个主体。提出这个主体，是为了抗衡、或者说为了掀翻笛卡尔式那种原子化的主体，或康德式那种纯粹理性的主体；取而代之的是一个参与到和不同客体互动中、处在一个相互交互（interactive）的网络里、比较具有能动性的东西。

我认为这是一个失败的范式，因为它实际上很庸俗，和普通人心里，或者和科学共同体、理工科知识分子、科学实在论者头脑中想象出来的那种比较迂腐、庸俗的主体对得上号。所以它是一个不太具有反思力的主体范式。

还有一个主体就是 subject。这是近代笛卡尔意义上的主体，实际上就叫主体。subject 这个词和两个东西相对应：一个是 object，即客体或对象；另一个是 substance，即实体。主体处在和 object、substance，也就是和对象、实体的这种关系里面，是一个三元关系。

接下来我们一个个细讲，先讲第一种主体 agent。

agent 带有一种平等主义的观点。我用一张图表示：如果这是一个世界，这就是整个 world，或者整个场域、整个 field。那么 agent 的话，一般人脑子里理解的主体——能动者、主动者，或者叫主动的个体——是主动认识、主动改变、主动去实践、主动去解释、把握其他对象的。这样的 agent 像什么？它好像游戏里的一个角色、一个英雄，he is a hero。

其他客体、其他 object 就是小兵，比他小，就是小兵。hero 和小兵之间会互相发生关系、关联，这种关联、这种意向性就会变成 phenomenon，变成一种现象。

现在的认知主义，或者一些具身化哲学认为，由这些现象就能够说明问题。他们把这种过程套用量子力学里的一种观点，把这个过程叫作 diffraction，即衍射。就好像你学了量子力学就会知道，现实物质本身是波函数衍生、衍射出来的产物，并不是有一个实体化的东西在里面。

所以他们认为，笛卡尔式的主体 subject，这种主体是一种现象；它是更为原初、更为原本的 agent 介入到关联、相互关系当中去。介入到这种相互关系当中的 agent 发生关系、发生关联之后，产生一种抽象出来的、比较普遍的现象，这个现象就会被把握成抽象的笛卡尔式主体性。这里会把一种相互关系错误地把握成一种单向关系，就变成一个原子化的主体。这个原子化主体悬空于整个 world 之上；subject 可以悬空于整个场域之上，对它发生一种认识，叫认知主体，一种纯粹的孤胆英雄式、上帝视角式的主体，可以认识整个世界。subject 可以把这整个东西，把自己的这个 agent 当成一个对象来加以认识。

这是当前哲学里比较流行的一种主体范式，叫 embodied agent，具身化的主体。有人不会把 agent 翻成主体，而叫具身化的能动者；他们喜欢说主动的个体、具身化的能动体、能动者，像特工一样。这个玩意儿兼有化身的含义，是代理，或者像一个代理平台；它是各式各样这种他者的代理平台。他们把他者叫作一种意志性的他者，它发生一种关系、建构性的关系，或者叫衍射，衍射出了这么一种实体化的中心。所以这种新的主体范式是去中心化的，是在这种相互关系当中去把握整个世界；它是以现象取代所谓的实体，取代所谓的本质性的东西。这是一些当前哲学家喜欢的做法，特别是法国人；我看英美分析哲学里也有好多人接受了这个范式，这个 embodied agent 范式。

齐泽克、拉康、黑格尔——在我看来是观念论哲学家——以及一些辩证唯物主义者、德里达、德勒兹，还有海德格尔，他们都不同意这个范式。这个范式是后来在资本主义学术异化下产生出来的，对哲学本身的革命性进行阉割的范式。这不是一个非常好的范式，因为它非常明显和我们日常生活中对主体的想象重叠：我们日常生活中就是把主体设想成一种日常的、矮化的主体。它是重点落在这个“体”上，你了解吗？主体落在个体上。

其实 subject 不是一个体，it's not body，它没有 embodied；subject 是没有 embodied 的。但我们中国人会把它翻译成 body。其实中国的官方哲学，或者说教科书里教的那个主体，就是主观能动体，实际上就是 agent。我甚至说我们大天朝的哲学教育领先国际，不知道领先多少年。因为统治阶级最敏锐，知道如何把哲学割一刀，让它变得庸俗一点、钝一点，让下面的聪明人陷于一种自我悖谬，或者不能够去把握真正关键的一些矛盾。这个东西和日常生活当中的想象图式非常紧密贴合：我们日常生活中就把世界想象成一个轴是空间，一个轴是时间。

然后一个 agent、一个主体就在这里面运动。空间是中心，从这个中心出发，它把握万事万物；他们会把这些万事万物把握成所谓的世界，或者事物，包括宇宙、自然、他人等等。这些东西都在这个矩阵里面，都是在这个场域里面的。这个主体也是一个平等的所谓“我”；一般他会身体化，会有身体；其次，它是一个中心化的，浓缩成一个中心。其实中国人对自我的把握就是非常非常 agent，it's very traditional Chinese thinking style，这是非常非常中国式的一种思维方式。我觉得这是中国传统哲学的一种思路：他把自我看成是一个自身；也有人把 agent 什么的翻译成自身、自身性。它是一个中心化的受体。

实际上，这玩意儿与其说是主体，不如说是受体。它当然也是个能动者，可以和其他东西发生关系。我们大部分人的自我意识的觉知就是这种，就是这种自身化，或者叫具身化。这个“我”字，我直接叫具身化的，然后是一个中心化的，是和其他东西同时在场的，在同一个场域里，在同一个当下的时间性和空间性的场域里共在。

这种共在就是在世存在。在海德格尔看来，这种存在很容易陷入一种常人状态：虽然自己还是个中心，但把自己当成各种物件当中的一个物件，把自我当成一个东西摆在这个空间场域里面，当然就变成所谓的自私——以自我为中心，所有的利益、好处都要往这个中心靠，他人都要为这个中心的第一人称体验、好恶，以及一些感性上的喜怒哀乐负责。这就是所谓的自私，所谓的中心化。那么中国人呢，就是要你跳出这个中心化的、具身化的我身，跳出自己身体的局限。老子说“及吾无身，吾有何患”，差不多是这个意思。人就是要跳出这个，能够镜像神经元发达一点，去感受别人的另一个神，感受一下，这就是所谓的人。这样建构起一个社会化的、人情关系的网络。中国哲学基本上就告诉你怎么在这个人情关系网络里面去把握一个尺寸，把握一种规则和潜规则，怎么去玩这个游戏。这个游戏大概来说是一个模板游戏；这种主体性 agent，就是游戏里面你可以操控的单位、可操控的英雄单位。所以这个主体是游戏里面的一个角色，所以它叫 agent。其实你如果玩过一些做游戏的软件——我花了几百块钱买的那个游戏软件——里面的那些动的单元，就叫 agent、能动者。那一个个游戏里面被控制的小对象，就叫一个 agent。那个游戏软件很明显把握住了这种哲学，体现出了这种哲学。

所谓自私、所谓中心化，就是要对感性上的喜怒哀乐负责。那么中国人呢，就是要你跳出这个中心化的、具身化的自我，跳出自己身体的局限。老子说“及吾无身，吾有何患”，差不多就是这个意思。人就是要跳出这个，镜像神经元才能发达一点，去感受别人的另一个“神”，感受一下另一个神。所谓的人就是这样，建构起一个社会化的人情关系网络。中国哲学基本上就是告诉你，怎么在这个人情关系网络里把握一个分寸，把握一种规则和潜规则，怎么去玩这个游戏。

那么这个游戏大致上就是一个模板游戏——我看就是模板游戏，实际上也是模板游戏。这种主体性 agent，就是游戏里你可以操控的单位，是可操控的英雄单位。所以这个主体，就是游戏里的一个角色，是你控制的一个角色，所以它叫 agent。

如果你玩过一些做游戏的软件，就会知道：我花了几百块钱买的那个游戏软件里，那些会动的单元就叫 agent，叫能动者。游戏里一个个被控制的小对象，就叫一个 agent。那个游戏软件很明显把握住了这种哲学，体现出了这种哲学。

这种对主体的理解，不是笛卡尔、康德、黑格尔、马克思的理解，也不是德里达、海德格尔、萨特等一系列哲学家所理解的 subject（主体）。比如费希特、谢林，他们把握的主体也不是这个 agent，不是这个玩意儿。

这个玩意儿是个很不哲学的概念。它是一锅端的那种：你是一个东西，是这套相互关系里面的一个临时存在。那些哲学家讨论主体的时候，讨论的并不是 agent。
