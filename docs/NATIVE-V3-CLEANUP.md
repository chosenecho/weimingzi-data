本次资料清理只删除复原配方，将正文输入选择器的来源名统一为 `blocks`，并把人工确认的原采用位置保存为 `revision` 目标上的 `order`。正文、原始输入、模型、原时间、质量观察、元数据来源、适用与采用事实逐条比对。原 ID 和工件字节保持不变。

文稿内容摘要采用机器契约列出的原生字段；输入引用同步指向该原生摘要。原始输入快照和来源观察中的历史摘要原样保留。源提交及转换证据记录旧文稿摘要与新摘要之间的映射，避免将表示方式变化当作新的识别或人工审核。
