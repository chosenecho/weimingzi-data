# 数据说明

## 收录范围

本仓库汇总未明子相关视频的转录、字幕、AI 阅读稿、音频索引，以及独立采集的动态、专栏、文集和合集。主要归档 UID 为 `23191782`；有关联的其他上传者、转载和联合投稿也会按原始来源保留。

当前目录数量见 [dataset-summary.json](../metadata/dataset-summary.json)。视频与分 P 来自 [catalog.csv](../metadata/catalog.csv)。用户内容数量来自 [summary.json](../data/user-content/summary.json)，并核对实际导出文件。历史统计属于当时的快照，不等于当前目录数量。

## 来源与处理层次

| 材料 | 来源记录 | 使用入口 |
| --- | --- | --- |
| B 站视频与分 P | 分 P 来源记录与原始响应 | [视频目录](VIDEO-INDEX.md) |
| YouTube 音轨 | YouTube 标识、原始识别响应与审计记录 | [跨平台目录](SOURCE-INDEX.md#youtube-音轨) |
| 用户补充音频 | 独立本地音频库及音频哈希 | [补充音频](../data/audio/README.md) |
| 动态、专栏与合集 | 响应、分页证据及数据库快照 | [用户内容](../data/user-content/README.md) |
| AI 阅读稿 | 阅读稿、校对记录与版本 | 各视频或音频目录 |
| 字句确认版本 | R01—R06 记录与局部校正版 | [训练源说明](TRAINING.md) |

整理和目录迁移保留原始文稿及音频哈希。原始 ASR、源字幕、AI 阅读稿与人工确认记录分开存储，不自动互相覆盖。

## 统计单位

- 视频以 BV 为目录单位；视频级 YouTube 映射不代表逐个分 P 精确对应。
- B 站分 P 以 `(bvid, page)` 去重，YouTube 音轨以 `youtube_id` 去重。
- 训练入口以选定的分 P 文稿为单位；训练入口数量不等于人工审核通过数量。
- 音频以当前媒体清单中的恢复路径去重；文件数不等于视频数。
- 动态、专栏正文、文集与合集分别计数，不与视频目录相加。

## 质量状态

| 状态或材料 | 含义 |
| --- | --- |
| 原始 ASR／源字幕 | 识别或上游字幕结果 |
| AI 阅读稿、needs-review | 经过 AI 处理，仍待人工复核 |
| 局部字句确认 | 只确认记录中的具体段落与术语 |
| requires_review／复核区间 | 有识别缺口、时间戳或其他待查问题 |
| 无识别正文 | 没有可用转录文本 |
| 缺少 SRT／VTT | 不能生成或尚未提供有效时间字幕 |

状态按各目录的版本记录、校对报告和[复核事项](../metadata/review-issues.json)解释。完整 AI 阅读稿不代表识别、说话人归属或训练样本已经全面审核。

## 已知限制

- 最新 ASR 补跑的直播 P1 仍有原始时间戳异常，保留正文与响应，不提供该 P 的 SRT／VTT。见[批次说明](../provenance/asr/2026-11-03-missing-local/README.md)。
- YouTube 中无正文、识别缺口和时间戳异常的材料仍保留对应标记。见[AI 校对批次](../provenance/ai-proofreading/2026-11-03-opencode-go/README.md)。
- 动态与专栏快照只覆盖采集时可见的材料；已删除、隐藏或无权限内容不在完整性范围，图片和音视频附件未全量下载。
- 静态来源索引中曾有仅存标题和元数据的不可访问条目；这些条目及误存的 HTML 封面已移出当前目录，历史情况见[清理记录](../provenance/cleanup/2026-11-03-invalid-entries/README.md)。
- 归档目录的元数据不是上传者身份或历史可播放性的独立证明。需要精确归属时，应检查各来源记录。
- AI 处理可能引入错字、遗漏或重述。引用具体发言时，应对照原始版本及可用音频。

## 复现与引用

使用数据时记录 Git 提交、相对路径、版本或模型、文件 SHA-256，以及采用的审核状态。训练用途应锁定 [training-source.json](../metadata/training-source.json)，不要跟随 main 自动替换训练源。

历史清单、SQLite 内的路径和原始响应保留采集时字段。新目录的解释方式见[批次与校验](PROVENANCE.md)。第三方内容没有统一再许可，见[内容权利说明](../CONTENT-RIGHTS.md)。
