# 数据说明

## 范围与入口

本仓库收录未明子相关的转录、字幕、AI 阅读稿、音频索引、动态、文章、文集和合集，也包含转录与校对的数据库、JSON 响应、CSV 清单和文本修订数据。主要采集对象为 UID `23191782`，另有转载、联合投稿和补充音频材料。

所有材料通过[分类目录](INDEX.md)和[主目录](../metadata/catalog.csv)查找。数据库与清单位于[数据集目录](../data/datasets/README.md)，当前数量见 [dataset-summary.json](../metadata/dataset-summary.json)。

## 统计单位

- 一份转录、分段或补充音轨对应一条转录记录；多个记录可以属于同一个内容条目。
- 一组数据库或结构化文件登记为一个数据集，README 列出组内文件。
- 动态、文章正文、文集和合集按各自数据格式单独计数。
- 音频按媒体清单中的恢复路径去重；文件数与内容条目数不相等。
- 训练选稿是用途选择，其数量不代表审核通过数量。

## 质量字段

| 状态或字段 | 含义 |
| --- | --- |
| 原始 ASR／字幕 | 识别或上游字幕结果 |
| AI 阅读稿、needs-review | 经过 AI 处理，仍待复核 |
| 局部字句确认 | 只确认明确记录的段落或术语 |
| requires_review | 有识别、时间戳或其他待查问题 |
| recognized_text_empty | 没有可用识别正文 |
| timed_exports_available | 是否有时间字幕导出 |
| human_reviewed | 已明确登记的人工复核状态 |

空值表示该字段未提供，不能解释为 False 或审核通过。AI 校对完成和完整阅读稿也不能作为全文人工审核结论。具体问题见[复核事项](../metadata/review-issues.json)、[校对数据](../data/datasets/校对数据/README.md)和[转录数据](../data/datasets/转录数据/README.md)。

存在无正文、识别缺口和时间戳异常的材料。无法提供有效 SRT／VTT 的条目保留正文及响应，不通过修改时间戳来制造可用字幕。局部确认内容见[文本修订数据](../data/datasets/文本修订/README.md)。

动态和文章仅覆盖采集时可见的内容，附件未全量下载。目录关联和元数据本身也不能证明逐段对齐、音轨一致或发言归属。引用具体发言时应核对原文和可用音频。

## 使用与引用

使用数据时记录 Git 提交、文件路径、版本或模型、SHA-256 及采用的质量状态。训练用途应锁定[选稿索引](../metadata/training-source.json)。资料中的路径字段按原记录格式读取，仓库文件定位以主目录为准。第三方内容使用条件见[内容权利说明](../CONTENT-RIGHTS.md)。
